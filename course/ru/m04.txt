# MODULE m04 | Переменные и типы | Как игра запоминает числа и слова

## LESSON m04-1 | Переменная — коробка с именем | 6
:: goals
- Что такое переменная
- Как создать её словом `var`
- Как напечатать и поменять значение

:: text Коробка с наклейкой
**Переменная** — коробка с наклейкой. На наклейке имя. Внутри значение.

Игре нужно много таких коробок: здоровье, очки, скорость, имя игрока.

Коробку создают словом `var` (от variable — переменная):

```gd
var health = 100
```
Читается так: «создай переменную `health` и положи в неё 100».

:: code
Переменную можно напечатать. Пиши её имя **без кавычек**.
```gd
extends Node

func _ready():
	var health = 100
	var player_name = "Аня"
	print(player_name)
	print(health)
```
```out
Аня
100
```
С кавычками `"health"` напечатается само слово health. Без кавычек — то, что лежит в коробке.

:: text Значение можно менять
Переменная на то и переменная — её содержимое можно заменить. `var` пишут только **один раз**, при создании. Дальше — просто имя и `=`.

```gd
var coins = 0
coins = 5      # теперь в коробке 5
coins = 12     # а теперь 12
```

!> Знак `=` здесь не «равно», а «положи в коробку». Справа — что положить, слева — куда.

:: code
`print` может напечатать несколько вещей подряд. Перечисли их через запятую.
```gd
extends Node

func _ready():
	var coins = 0
	print("Монет: ", coins)
	coins = 7
	print("Монет: ", coins)
```
```out
Монет: 0
Монет: 7
```
`print` склеивает части **без пробелов**. Поэтому пробел мы поставили сами — внутри кавычек после двоеточия.

:: text Как называть переменные
- Латиница, цифры и `_`. Цифра не может стоять первой.
- Маленькие буквы, слова через подчёркивание: `max_speed`, `player_name`.
- Имя должно объяснять, что внутри. `jump_height` лучше, чем `jh`.

> Этот стиль называется snake_case («змеиный»). Так принято в GDScript.

:: quiz
Какое имя переменной написано в стиле GDScript?
[ ] `MaxSpeed` => Так в GDScript называют классы, а не переменные.
[x] `max_speed` => Верно. Маленькие буквы и подчёркивание.
[ ] `max-speed` => Дефис — это минус. Godot прочитает «max минус speed».

:: fill
Создай переменную `lives` со значением 3 и напечатай её.
```gd
extends Node

func _ready():
	___ lives = 3
	print(___)
```
= var
= lives
explain: `var` создаёт переменную, а `print(lives)` печатает то, что в ней лежит.

:: recap
- `var имя = значение` создаёт переменную.
- Дальше значение меняют без `var`: `имя = новое_значение`.
- `print("Текст: ", имя)` — печать нескольких частей подряд, без пробелов между ними.
- Имена — в snake_case: `player_name`.

## LESSON m04-2 | Числа и арифметика | 7
:: goals
- Целые и дробные числа
- Знаки `+ - * /` и `%`
- Ловушка целого деления

:: text Два вида чисел
В GDScript два вида чисел:

- **int** (integer, целое) — без точки: `0`, `7`, `-15`, `1000`.
- **float** (дробное) — с точкой: `3.5`, `0.1`, `-2.0`, `9.81`.

!> Дробную часть отделяют **точкой**, а не запятой: `2.5`, не `2,5`.

:: code
Godot умеет считать.
```gd
extends Node

func _ready():
	print(2 + 3)
	print(10 - 4)
	print(6 * 7)
	print(2 + 3 * 4)
	print((2 + 3) * 4)
```
```out
5
6
42
14
20
```
Порядок как в школе: сначала `*` и `/`, потом `+` и `-`. Скобки меняют порядок.

:: text Ловушка: деление целых
Если делить **целое на целое**, Godot отбрасывает дробную часть:

```gd
print(7 / 2)     # 3, а не 3.5!
print(7.0 / 2)   # 3.5
```

Чтобы получить дробный ответ, хотя бы одно число должно быть дробным: `7.0` вместо `7`.

В Godot за такое деление появится жёлтое предупреждение `INTEGER_DIVISION`. Это не ошибка, а напоминание: «ты точно хотел целое?».

:: code
Знак `%` — **остаток от деления**. Очень полезен: например, проверить, чётное ли число.
```gd
extends Node

func _ready():
	print(7 / 2)
	print(7 % 2)
	print(10 % 5)
	print(7.0 / 2)
```
```out
3
1
0
3.5
```
7 делим на 2: получается 3 и остаток 1. Если остаток от деления на 2 равен 0 — число чётное.

:: quiz
Что напечатает `print(9 / 2)`?
[ ] `4.5` => Оба числа целые, поэтому дробная часть отбрасывается.
[x] `4` => Верно. Целое делить на целое — получится целое.
[ ] Ошибку => Ошибки нет, будет только предупреждение в Godot.

:: quiz
Чему равно `17 % 5`?
[ ] `3` => 3 — это сколько раз 5 помещается в 17. А `%` даёт остаток.
[x] `2` => Верно. 5 × 3 = 15, до 17 остаётся 2.
[ ] `3.4` => Это результат обычного деления дробных чисел.

:: task
У игрока 250 монет. Меч стоит 60 монет. Напечатай, сколько мечей он может купить и сколько монет останется. Нужно два числа, по одному в строке:
```text
4
10
```
```gd
extends Node

func _ready():
	var coins = 250
	var price = 60
	# напечатай сколько мечей
	# напечатай остаток
```
```solution
extends Node

func _ready():
	var coins = 250
	var price = 60
	print(coins / price)
	print(coins % price)
```
```expect
4
10
```
hint: Сколько мечей — это деление целых: `coins / price`.
hint: Остаток — знак `%`.

:: recap
- `int` — целые числа, `float` — дробные (через точку).
- `+ - * /`, скобки меняют порядок.
- **Целое / целое = целое**: `7 / 2` даёт `3`. Нужна дробь — пиши `7.0`.
- `%` — остаток от деления.

## LESSON m04-3 | Текст и склейка | 7
:: goals
- Что такое строка
- Как склеить строки
- Как вставить число в текст

:: text Строка — это текст
Текст в программировании называют **строкой** (String). Строку пишут в кавычках: `"Привет"`.

Строки можно **склеивать** знаком `+`:

```gd
var player_name = "Аня"
print("Привет, " + player_name + "!")   # Привет, Аня!
```

:: code
А вот так нельзя: склеить строку и число. Запусти.
```gd
extends Node

func _ready():
	var coins = 5
	print("Монет: " + coins)
```
fails: yes
Godot не знает, как сложить текст и число. Это разные **типы**. Нужно превратить число в текст функцией `str()`.

:: code
`str(число)` превращает число в текст. Теперь склейка работает.
```gd
extends Node

func _ready():
	var coins = 5
	print("Монет: " + str(coins))
	print("Монет: ", coins)
```
```out
Монет: 5
Монет: 5
```
Второй способ — через запятую в `print` — превращает всё в текст сам. Но `+` и `str()` пригодятся, когда текст нужен не для печати, а, например, для надписи на экране.

:: text Шаблон с %
Есть третий способ — **шаблон**. В тексте ставят метки, а значения подставляют после знака `%`:

- `%s` — любое значение;
- `%d` — целое число;
- `%.2f` — дробное, 2 знака после точки.

```gd
var hp = 75
print("Здоровье: %d%%" % hp)            # Здоровье: 75%
print("%s набрал %d очков" % ["Аня", 30])  # Аня набрал 30 очков
```

Если меток несколько, значения пишут в квадратных скобках через запятую. `%%` — это сам знак процента.

:: code
```gd
extends Node

func _ready():
	var player_name = "Кира"
	var time = 12.3456
	print("Игрок %s прошёл уровень за %.1f сек" % [player_name, time])
```
```out
Игрок Кира прошёл уровень за 12.3 сек
```
Поменяй `%.1f` на `%.3f` и посмотри, что изменится.

:: fill
Заполни пропуск, чтобы склейка сработала.
```gd
extends Node

func _ready():
	var level = 3
	print("Уровень " + ___(level))
```
= str
explain: `str()` превращает число в строку, и `+` может её склеить.

:: task
Даны имя и очки. Напечатай ровно такую строку: `Лис: 120 очков`
```gd
extends Node

func _ready():
	var player_name = "Лис"
	var score = 120
```
```solution
extends Node

func _ready():
	var player_name = "Лис"
	var score = 120
	print(player_name + ": " + str(score) + " очков")
```
```expect
Лис: 120 очков
```
hint: Подойдёт любой способ: `+` и `str()`, запятые в `print` или шаблон `%s: %d очков`.
hint: Следи за пробелами: после двоеточия и перед словом «очков».

:: recap
- Строка — текст в кавычках, тип `String`.
- `+` склеивает строки. Число сначала превращают в текст: `str(5)`.
- Шаблон: `"%s: %d" % [имя, число]`.

## LESSON m04-4 | Типы и подсказки типов | 8
:: goals
- Четыре главных типа
- Как указать тип переменной
- Что такое `:=`

:: text Четыре главных типа
У каждого значения есть **тип** — вид данных:

- `int` — целое число: `10`;
- `float` — дробное: `2.5`;
- `String` — текст: `"кот"`;
- `bool` — да или нет: `true` (правда) или `false` (ложь).

`bool` нужен для вопросов «да/нет»: жив ли игрок, открыта ли дверь, нажата ли кнопка.

```gd
var is_alive = true
var door_open = false
```

:: text Можно указать тип явно
После имени переменной можно поставить двоеточие и тип:

```gd
var health: int = 100
var speed: float = 200.0
var player_name: String = "Аня"
```

Это **подсказка типа**. Теперь Godot следит: в `health` можно класть только целые числа. Положишь текст — получишь ошибку **сразу**, а не когда-нибудь потом в игре.

:: code
Запусти. Godot не даст положить текст в переменную типа `int`.
```gd
extends Node

func _ready():
	var health: int = 100
	health = "много"
	print(health)
```
fails: yes
Это хорошая ошибка. Она ловит опечатку до того, как игра сломается у игрока.

:: text Короткая запись :=
Писать тип руками долго. Есть сокращение `:=` — «тип возьми из значения»:

```gd
var health := 100      # Godot понял: int
var speed := 200.0     # float
var title := "Меню"    # String
```

Это то же самое, что `var health: int = 100`, только короче.

> В этом курсе мы часто пишем просто `var x = 5`, чтобы не отвлекаться. В своих проектах лучше привыкать к `:=` или `: тип` — ошибок будет меньше.

:: code
Функция `typeof` и слово `is` помогают узнать тип.
```gd
extends Node

func _ready():
	var a := 5
	var b := 5.0
	print(a is int)
	print(b is int)
	print(b is float)
```
```out
true
false
true
```
`5` и `5.0` — разные типы, хотя число одно.

:: quiz
Какой тип у значения `false`?
[ ] `String` => Строка была бы в кавычках: `"false"`.
[ ] `int` => Целые числа — это цифры.
[x] `bool` => Верно. `true` и `false` — два значения типа bool.

:: quiz
Что значит `var speed := 3.5`?
[x] Создать переменную, тип взять из значения: float => Верно. `:=` выводит тип сам.
[ ] Сравнить speed с 3.5 => Сравнение пишется `==`. Будет позже.
[ ] Ошибка: так писать нельзя => Можно, это короткая запись подсказки типа.

:: recap
- Главные типы: `int`, `float`, `String`, `bool`.
- `var x: int = 5` — явная подсказка типа.
- `var x := 5` — тип берётся из значения.
- С типами Godot ловит ошибки раньше.

## LESSON m04-5 | Константы и сокращения | 6
:: goals
- Что такое константа
- Как писать `+=` и `-=`

:: text Константа — запечатанная коробка
Некоторые значения не должны меняться никогда: сила гравитации, максимальное здоровье, скорость прыжка.

Для них есть **константа**: `const` вместо `var`.

```gd
const MAX_HEALTH = 100
const GRAVITY = 980.0
```

Имена констант пишут **БОЛЬШИМИ_БУКВАМИ**. Так их сразу видно в коде.

Попробуешь поменять константу — Godot выдаст ошибку. Это защита от случайностей.

:: text Сокращения
Часто нужно изменить значение относительно старого: «прибавь 1», «отними 10».

```gd
coins = coins + 1    # длинно
coins += 1           # коротко, то же самое
```

Так же работают `-=`, `*=`, `/=`.

```gd
health -= 10    # отнять 10
speed *= 2      # удвоить
```

:: code
```gd
extends Node

const MAX_HEALTH = 100

func _ready():
	var health = MAX_HEALTH
	health -= 30
	print(health)
	health += 5
	print(health)
	health *= 2
	print(health)
```
```out
70
75
150
```

:: code
А теперь попробуем поменять константу.
```gd
extends Node

const LIVES = 3

func _ready():
	LIVES = 5
	print(LIVES)
```
fails: yes
Если значение должно меняться — это `var`, а не `const`.

:: quiz
Что напечатает код?
```gd
var x = 10
x += 5
x -= 3
print(x)
```
[ ] `10` => Значение меняли дважды: +5, потом −3.
[x] `12` => Верно. 10 + 5 − 3 = 12.
[ ] `15` => Это после `+= 5`. Но потом ещё `-= 3`.

:: recap
- `const ИМЯ = значение` — константа, её нельзя менять.
- `x += 1` — то же, что `x = x + 1`. Есть `-=`, `*=`, `/=`.

## LESSON m04-p | Практика: карточка персонажа | 8 | practice
:: goals
- Собрать всё про переменные в одной программе

:: task
Создай переменные:
- `hero_name` — `"Рыцарь"`;
- `level` — `5`;
- `health` — `80`.

Герой получил урон 25 и выпил зелье +10. Напечатай ровно так:
```text
Рыцарь, уровень 5
Здоровье: 65
```
```gd
extends Node

func _ready():
	# создай переменные
	# измени здоровье
	# напечатай две строки
	pass
```
```solution
extends Node

func _ready():
	var hero_name = "Рыцарь"
	var level = 5
	var health = 80
	health -= 25
	health += 10
	print(hero_name, ", уровень ", level)
	print("Здоровье: ", health)
```
```expect
Рыцарь, уровень 5
Здоровье: 65
```
hint: `var hero_name = "Рыцарь"` — и так же остальные.
hint: Урон — `health -= 25`, зелье — `health += 10`.
hint: Запятые в `print` склеивают без пробелов. Пробел после запятой в тексте `", уровень "` ставь сам.

:: task
Посчитай среднее время прохождения трёх попыток: 12, 15 и 14 секунд. Напечатай с одним знаком после точки:
```text
Среднее: 13.7
```
```gd
extends Node

func _ready():
	var a = 12
	var b = 15
	var c = 14
```
```solution
extends Node

func _ready():
	var a = 12
	var b = 15
	var c = 14
	var avg = (a + b + c) / 3.0
	print("Среднее: %.1f" % avg)
```
```expect
Среднее: 13.7
```
hint: Сумма в скобках, потом деление на 3.
hint: Если делить на `3`, получится целое 13. Дели на `3.0`.
hint: Один знак после точки — шаблон `"%.1f" % avg`.

:: deep Почему 0.1 + 0.2 не ровно 0.3
Компьютер хранит дробные числа в двоичном виде. Некоторые дроби, например 0.1, нельзя записать точно — как 1/3 нельзя точно записать десятичной дробью (0.3333…).

Поэтому `0.1 + 0.2` внутри компьютера — это 0.30000000000000004. Godot при печати округляет и показывает `0.3`, но сравнение `0.1 + 0.2 == 0.3` даст `false`.

Для сравнения дробных чисел в Godot есть функция `is_equal_approx(a, b)` — «примерно равны».
```gd
extends Node

func _ready():
	print(0.1 + 0.2 == 0.3)
	print(is_equal_approx(0.1 + 0.2, 0.3))
```
```out
false
true
```

:: recap
- Переменные хранят состояние героя: имя, уровень, здоровье.
- `+=` и `-=` меняют значение относительно старого.
- Для дробного результата дели на дробное число: `3.0`.
