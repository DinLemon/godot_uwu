# MODULE m12 | Физика и столкновения | Персонаж, стены, гравитация и прыжок

## LESSON m12-1 | Четыре вида тел | 7
:: goals
- Какие узлы отвечают за физику
- Чем они отличаются
- Что такое форма столкновения

:: text Тела в Godot
visual: concept-m12
Чтобы предметы сталкивались, им нужно **тело** (body). В 2D есть четыре главных узла:

- **StaticBody2D** — неподвижное: пол, стены, платформы. Само не двигается, но об него ударяются.
- **CharacterBody2D** — персонаж. Двигается так, как скажет **твой код**. Упирается в стены.
- **RigidBody2D** — предмет, которым управляет **физика**: ящик, мяч. Падает, катится, отскакивает сам.
- **Area2D** — зона. Ни во что не упирается, но **замечает**, кто в неё вошёл: монетка, шипы, финиш.

:: text Форма — обязательна
Само тело не знает своих размеров. Ему нужен ребёнок **CollisionShape2D** с формой: прямоугольник, круг, капсула.

```tree
Player (CharacterBody2D)
├── Sprite2D           ← как выглядит
└── CollisionShape2D   ← какой формы для физики
```

Картинка и форма — разные вещи. Картинка может быть сложной, а форма — простым прямоугольником. Так быстрее.

!> Если забыть CollisionShape2D, рядом с телом в дереве появится жёлтый треугольник с предупреждением. Тело будет проходить сквозь всё.

:: quiz
Какой узел выбрать для монетки, которую персонаж подбирает, проходя через неё?
[ ] StaticBody2D => Персонаж упрётся в монетку, как в стену.
[ ] RigidBody2D => Монетка начнёт падать и катиться.
[x] Area2D => Верно. Зона замечает вход, но не мешает движению.

:: quiz
Ты делаешь ящик, который можно толкнуть, и он сам упадёт с края. Какой узел?
[x] RigidBody2D => Верно. Им управляет физика: гравитация, толчки, удары.
[ ] CharacterBody2D => Им управляет только твой код. Сам он падать не будет.
[ ] Area2D => Зона не сталкивается с предметами.

:: recap
- **StaticBody2D** — стены и пол. **CharacterBody2D** — персонаж (двигает код).
- **RigidBody2D** — двигает физика. **Area2D** — зона, замечает вход.
- Каждому телу нужен ребёнок **CollisionShape2D** с формой.

## LESSON m12-2 | CharacterBody2D и move_and_slide | 8
:: goals
- Как двигать персонажа правильно
- Что такое `velocity`

:: text Не position, а velocity
С `CharacterBody2D` позицию **не меняют напрямую**. Иначе персонаж пройдёт сквозь стены.

Правильно так:
1. Записать желаемую скорость в свойство `velocity` (Vector2, пикселей в секунду).
2. Вызвать `move_and_slide()`.

`move_and_slide()` сам умножит скорость на delta, сдвинет персонажа и **остановит у стены**. Если упрёшься в стену под углом — скользнёшь вдоль неё. Отсюда и «slide».

:: text _physics_process
Физику считают в функции `_physics_process(delta)`, а не в `_process`. Она вызывается ровно 60 раз в секунду, всегда с одинаковой `delta`. Так физика стабильнее.

```gd
extends CharacterBody2D

var speed = 200

func _physics_process(delta):
	var dir = Input.get_axis("ui_left", "ui_right")
	velocity.x = dir * speed
	move_and_slide()
```

Заметь: тут **нет** `* delta`. Его делает `move_and_slide()` сам.

:: code
В тренажёре стен нет, но `move_and_slide()` двигает персонажа по `velocity`.
```gd
extends CharacterBody2D
# тренажёр: кадров=3 дельта=0.5 нажато=ui_right

var speed = 200

func _physics_process(delta):
	var dir = Input.get_axis("ui_left", "ui_right")
	velocity.x = dir * speed
	move_and_slide()
	print(position)
```
```out
(100.0, 0.0)
(200.0, 0.0)
(300.0, 0.0)
```

:: quiz
Почему персонажу на CharacterBody2D не меняют `position` напрямую?
[x] Он пройдёт сквозь стены — `move_and_slide` останавливает у препятствий => Верно.
[ ] Это вызовет ошибку => Ошибки не будет, но столкновения перестанут работать.
[ ] `position` у него нет => Есть, просто двигать надо через `velocity`.

:: recap
- У CharacterBody2D меняют `velocity`, потом вызывают `move_and_slide()`.
- `move_and_slide()` сам учитывает delta и стены.
- Физику пишут в `_physics_process(delta)`.

## LESSON m12-3 | Гравитация и прыжок | 9
:: goals
- Как сделать падение
- Как прыгать только с земли

:: text Гравитация — это ускорение вниз
Гравитация каждую секунду прибавляет скорость **вниз**. Вниз — это **плюс** по y.

```gd
var gravity = 980.0   # пикселей в секунду за секунду

func _physics_process(delta):
	if not is_on_floor():
		velocity.y += gravity * delta
```

Здесь `* delta` нужен: мы меняем **скорость**, а не позицию.

`is_on_floor()` — стоит ли персонаж на полу. Работает после `move_and_slide()`.

> В новых версиях Godot вместо своей переменной можно писать `velocity += get_gravity() * delta`. Это гравитация из настроек проекта.

:: text Прыжок — толчок вверх
Прыжок — мгновенно поставить скорость **вверх**, то есть **отрицательный** y:

```gd
const JUMP_VELOCITY = -400.0

if Input.is_action_just_pressed("jump") and is_on_floor():
	velocity.y = JUMP_VELOCITY
```

Дальше гравитация сама замедлит подъём и вернёт персонажа вниз. Получается дуга.

`and is_on_floor()` не даёт прыгать в воздухе.

:: code
В тренажёре пол можно включить настройкой `пол=0`: всё, что ниже y = 0, считается полом. Прыжок нажат на 2-м кадре. Кадр = 0.1 секунды.
```gd
extends CharacterBody2D
# тренажёр: кадров=8 дельта=0.1 нажато=jump@2 пол=0

const JUMP_VELOCITY = -400.0
var gravity = 1000.0

func _physics_process(delta):
	if not is_on_floor():
		velocity.y += gravity * delta
	if Input.is_action_just_pressed("jump") and is_on_floor():
		velocity.y = JUMP_VELOCITY
	move_and_slide()
	print(snapped(position.y, 0.1), "  на полу: ", is_on_floor())
```
```out
0.0  на полу: true
-40.0  на полу: false
-70.0  на полу: false
-90.0  на полу: false
-100.0  на полу: false
-100.0  на полу: false
-90.0  на полу: false
-70.0  на полу: false
```
Персонаж взлетел на 100 пикселей, на 5-м и 6-м кадрах завис в верхней точке и пошёл вниз. `snapped(x, 0.1)` округляет до десятых — чтобы числа были ровными.

:: fill
Допиши прыжок: только с пола и только в момент нажатия.
```gd
extends CharacterBody2D

const JUMP_VELOCITY = -400.0

func _physics_process(delta):
	if Input.___("jump") and ___():
		velocity.y = JUMP_VELOCITY
	move_and_slide()
```
= is_action_just_pressed
= is_on_floor
explain: Прыжок — одно нажатие (`just_pressed`) и только с пола (`is_on_floor`).

:: quiz
Почему скорость прыжка отрицательная: `-400`?
[x] В Godot y растёт вниз, а прыгаем вверх => Верно.
[ ] Чтобы прыжок был слабее => Сила задаётся числом. Знак — это направление.
[ ] Это ошибка, должно быть 400 => С `+400` персонаж «прыгнет» в пол.

:: recap
- Гравитация: `velocity.y += gravity * delta`, пока не на полу.
- Прыжок: `velocity.y = JUMP_VELOCITY` (отрицательное число).
- `is_on_floor()` — стоит ли на полу. Без него можно прыгать в воздухе.

## LESSON m12-4 | Практика: платформер-персонаж | 12 | practice
:: goals
- Собрать персонажа, который бегает и прыгает
- Сделать пол

:: steps Пол
visual: guide-m12-4-0
Создадим новую сцену-уровень.
- **Scene → New Scene**. Корень — **Node2D**, переименуй в `Level`. Сохрани как `level.tscn`.
- Добавь ребёнка **StaticBody2D**, назови `Floor`.
- В `Floor` добавь **CollisionShape2D**. В Инспекторе в поле **Shape** выбери **New RectangleShape2D**.
- Растяни прямоугольник оранжевыми точками в широкую полосу внизу синей рамки.
- Чтобы пол было видно, добавь в `Floor` узел **ColorRect** и растяни его так же. (Или включи **Debug → Visible Collision Shapes** — формы будут видны при запуске.)

:: steps Персонаж
visual: guide-m12-4-1
- Нажми **Scene → New Scene**, выбери **Other Node** → **CharacterBody2D**. Назови `Player`.
- Добавь в него **Sprite2D** и перетащи `icon.svg` в **Texture**.
- Добавь **CollisionShape2D**, Shape → **New RectangleShape2D**. Подгони под картинку.
- Прикрепи к `Player` скрипт. В окне создания в **Template** выбери **CharacterBody2D: Basic Movement**. Нажми **Create**.
- Сохрани сцену как `player.tscn`.

:: code
Вот примерно такой скрипт создаст Godot по шаблону. Прочитай: ты уже знаешь каждую строку.
```gd
extends CharacterBody2D

const SPEED = 300.0
const JUMP_VELOCITY = -400.0

func _physics_process(delta):
	# Гравитация
	if not is_on_floor():
		velocity += get_gravity() * delta

	# Прыжок
	if Input.is_action_just_pressed("ui_accept") and is_on_floor():
		velocity.y = JUMP_VELOCITY

	# Влево-вправо и плавная остановка
	var direction = Input.get_axis("ui_left", "ui_right")
	if direction:
		velocity.x = direction * SPEED
	else:
		velocity.x = move_toward(velocity.x, 0, SPEED)

	move_and_slide()
```
norun: yes
`if direction:` — то же, что `if direction != 0:`. Ноль считается «ложью». `move_toward(velocity.x, 0, SPEED)` плавно гасит скорость до нуля.

:: steps Собираем
visual: guide-m12-4-2
- Открой `level.tscn`. Перетащи файл `player.tscn` из FileSystem в окно 2D, над полом.
- Нажми `F6`. Стрелки — бег, пробел или Enter — прыжок.
- Поменяй в скрипте `ui_accept` на своё действие `jump`, а `ui_left`/`ui_right` — на `move_left`/`move_right` из модуля 11.
- Попробуй числа: `SPEED = 150`, `JUMP_VELOCITY = -600`. Как меняется ощущение?

:: recap
- Уровень: StaticBody2D + CollisionShape2D — пол.
- Персонаж: CharacterBody2D + Sprite2D + CollisionShape2D + скрипт.
- Шаблон **Basic Movement** даёт готовый бег и прыжок.

## LESSON m12-5 | Слои столкновений | 6
:: goals
- Что такое слои и маски
- Как сделать, чтобы враги не сталкивались друг с другом

:: text Кто с кем сталкивается
Иногда не всё должно сталкиваться со всем. Враги не должны толкать друг друга. Пули игрока не должны попадать в самого игрока.

Для этого у каждого тела есть два набора галочек в Инспекторе, в разделе **Collision**:

- **Layer** (слой) — «на каком я этаже»;
- **Mask** (маска) — «с какими этажами я сталкиваюсь».

Тело A заденет тело B, если в **маске** A отмечен **слой** B.

:: text Пример
Договоримся:
- слой 1 — мир (стены, пол);
- слой 2 — игрок;
- слой 3 — враги.

Тогда:
- Игрок: Layer 2, Mask 1 и 3 — стоит на полу и бьётся о врагов.
- Враг: Layer 3, Mask 1 и 2 — стоит на полу, видит игрока, но **не** других врагов.

> Слоям можно дать имена: **Project Settings → Layer Names → 2D Physics**. Тогда вместо номеров будут «world», «player», «enemies».

:: quiz
Враг на слое 3 с маской 1. Игрок на слое 2. Столкнётся ли враг с игроком?
[ ] Да => В маске врага только слой 1. Слоя 2 там нет.
[x] Нет => Верно. Враг видит только слой 1 — мир.
[ ] Только если игрок прыгнет => Прыжок не меняет слои.

:: recap
- **Layer** — на каком слое тело. **Mask** — с какими слоями оно сталкивается.
- Разные слои для мира, игрока, врагов, пуль решают, кто с кем сталкивается.
