# MODULE m06 | Массивы и циклы | Списки и повторение

## LESSON m06-1 | Массив — список | 7
:: goals
- Что такое массив
- Как взять элемент по номеру
- Почему счёт идёт с нуля

:: text Список в одной переменной
**Массив** (Array) — переменная, в которой лежит **список** значений. Пишется в квадратных скобках через запятую:

```gd
var inventory = ["меч", "щит", "зелье"]
var scores = [10, 25, 7]
```

Удобно: не нужно заводить `item1`, `item2`, `item3`. Всё в одном месте.

:: text Номера начинаются с нуля
У каждого элемента есть **номер** (индекс). Счёт идёт с **нуля**:

```text
inventory = ["меч", "щит", "зелье"]
номер:          0       1       2
```

Взять элемент: имя массива и номер в квадратных скобках.

```gd
print(inventory[0])   # меч
print(inventory[2])   # зелье
```

**Аналогия:** этажи в некоторых странах. Первый этаж — «нулевой».

:: code
```gd
extends Node

func _ready():
	var inventory = ["меч", "щит", "зелье"]
	print(inventory)
	print(inventory[1])
	print(inventory.size())
	inventory[1] = "лук"
	print(inventory)
```
```out
["меч", "щит", "зелье"]
щит
3
["меч", "лук", "зелье"]
```
`size()` — сколько элементов. Элемент можно заменить через `=`.

:: code
Номер 3 в массиве из трёх элементов — это уже за краем. Запусти.
```gd
extends Node

func _ready():
	var inventory = ["меч", "щит", "зелье"]
	print(inventory[3])
```
fails: yes
Последний номер — всегда `size() - 1`. Есть хитрость: `inventory[-1]` — последний элемент, `[-2]` — предпоследний.

:: quiz
`var a = [5, 8, 13, 21]`. Что напечатает `print(a[2])`?
[ ] `8` => Это `a[1]`. Счёт с нуля: 5 — нулевой, 8 — первый.
[x] `13` => Верно. 0 → 5, 1 → 8, 2 → 13.
[ ] `21` => Это `a[3]` — последний.

:: recap
- Массив — список в квадратных скобках: `[1, 2, 3]`.
- Номера (индексы) идут с **0**. Последний — `size() - 1` или `[-1]`.
- `массив[номер]` — взять или заменить элемент.

## LESSON m06-2 | Методы массива | 7
:: goals
- Как добавить и удалить элемент
- Как проверить, есть ли элемент в списке

:: text Массив умеет делать дела сам
У массива есть **методы** — действия, которые вызываются через точку: `массив.действие()`.

- `append(x)` — добавить в конец;
- `erase(x)` — удалить первый такой элемент;
- `remove_at(i)` — удалить элемент с номером i;
- `has(x)` — есть ли x в списке (true/false);
- `size()` — длина;
- `is_empty()` — пустой ли;
- `sort()` — отсортировать;
- `pop_back()` — забрать последний элемент.

:: code
```gd
extends Node

func _ready():
	var bag = ["яблоко"]
	bag.append("ключ")
	bag.append("монета")
	print(bag)
	print(bag.has("ключ"))
	bag.erase("яблоко")
	print(bag)
	print(bag.size())
```
```out
["яблоко", "ключ", "монета"]
true
["ключ", "монета"]
2
```

:: text Слово in
Вместо `has()` можно написать `in` — читается почти как по-русски:

```gd
if "ключ" in bag:
	print("Дверь открыта")
```

:: fill
Добавь в массив `"щит"` и проверь, есть ли там `"меч"`.
```gd
extends Node

func _ready():
	var items = ["меч"]
	items.___("щит")
	print(items.___("меч"))
```
= append | push_back
= has
explain: `append` добавляет в конец, `has` отвечает true или false.

:: task
В рюкзаке `["камень", "палка", "камень"]`. Удали один `"камень"`, добавь `"верёвка"` и напечатай массив и его длину:
```text
["палка", "камень", "верёвка"]
3
```
```gd
extends Node

func _ready():
	var bag = ["камень", "палка", "камень"]
```
```solution
extends Node

func _ready():
	var bag = ["камень", "палка", "камень"]
	bag.erase("камень")
	bag.append("верёвка")
	print(bag)
	print(bag.size())
```
```expect
["палка", "камень", "верёвка"]
3
```
hint: `erase` удаляет только **первый** найденный элемент.
hint: Длина — `bag.size()`.

:: recap
- Методы вызывают через точку: `bag.append("ключ")`.
- `append`, `erase`, `remove_at`, `has`, `size`, `sort`, `is_empty`.
- `x in массив` — то же, что `массив.has(x)`.

## LESSON m06-3 | Цикл for | 8
:: goals
- Как повторить действие для каждого элемента
- Как повторить действие N раз

:: text Сделать для каждого
Часто нужно сделать одно и то же с каждым элементом списка: нанести урон каждому врагу, нарисовать каждую жизнь.

Для этого есть цикл `for` («для»):

```gd
for item in inventory:
	print(item)
```

Читается: «для каждого `item` в `inventory` — напечатай его». Переменная `item` по очереди принимает каждое значение списка.

:: code
```gd
extends Node

func _ready():
	var enemies = ["слизень", "гоблин", "дракон"]
	for enemy in enemies:
		print("Атакую: ", enemy)
	print("Все атакованы")
```
```out
Атакую: слизень
Атакую: гоблин
Атакую: дракон
Все атакованы
```
Блок с отступом повторился три раза. Строка без отступа — один раз, после цикла.

:: text Повторить N раз
Чтобы повторить что-то 5 раз, используй `range(5)` — это числа `0, 1, 2, 3, 4`:

```gd
for i in range(5):
	print(i)
```

Варианты `range`:
- `range(5)` → 0, 1, 2, 3, 4 (пять чисел, **без** 5);
- `range(2, 6)` → 2, 3, 4, 5;
- `range(0, 10, 2)` → 0, 2, 4, 6, 8 (шаг 2).

> В Godot 4 можно ещё короче: `for i in 5:` — то же, что `range(5)`.

:: code
```gd
extends Node

func _ready():
	for i in range(1, 4):
		print("Волна ", i)
	var total = 0
	for n in [10, 20, 30]:
		total += n
	print("Сумма: ", total)
```
```out
Волна 1
Волна 2
Волна 3
Сумма: 60
```
Второй цикл копит сумму в переменной `total`. Это очень частый приём.

:: quiz
Сколько раз напечатается «Hi»?
```gd
for i in range(2, 5):
	print("Hi")
```
[ ] 5 => `range(2, 5)` — это 2, 3, 4.
[x] 3 => Верно. Числа 2, 3 и 4.
[ ] 2 => Посчитай: 2, 3, 4 — три числа.

:: task
Даны цены `[30, 15, 55, 20]`. Посчитай общую стоимость и напечатай:
```text
Итого: 120
```
```gd
extends Node

func _ready():
	var prices = [30, 15, 55, 20]
	var total = 0
```
```solution
extends Node

func _ready():
	var prices = [30, 15, 55, 20]
	var total = 0
	for p in prices:
		total += p
	print("Итого: ", total)
```
```expect
Итого: 120
```
hint: `for p in prices:` — и внутри прибавляй `p` к `total`.
hint: `print` ставь **после** цикла, без отступа цикла. Иначе он напечатает 4 раза.

:: recap
- `for x in массив:` — повторить блок для каждого элемента.
- `for i in range(n):` — повторить n раз, i = 0…n−1.
- Чтобы что-то посчитать, заведи переменную до цикла и меняй её внутри.

## LESSON m06-4 | while, break, continue | 7
:: goals
- Цикл «пока условие верно»
- Как выйти из цикла раньше
- Как пропустить один шаг

:: text while — «пока»
`while` повторяет блок, **пока** условие верно:

```gd
var hp = 10
while hp > 0:
	hp -= 3
	print(hp)
```

!> Если условие никогда не станет ложным, цикл будет крутиться вечно — игра зависнет. В теле `while` что-то обязательно должно менять условие.

:: code
```gd
extends Node

func _ready():
	var energy = 10
	var steps = 0
	while energy > 0:
		energy -= 3
		steps += 1
	print("Шагов: ", steps)
	print("Энергия: ", energy)
```
```out
Шагов: 4
Энергия: -2
```

:: text break и continue
- `break` — выйти из цикла **сразу**.
- `continue` — пропустить остаток блока и перейти к следующему шагу цикла.

```gd
for n in [3, 8, -1, 5]:
	if n < 0:
		break        # дальше не идём
	print(n)
# напечатает 3 и 8
```

:: code
```gd
extends Node

func _ready():
	for i in range(1, 8):
		if i % 2 == 0:
			continue
		if i > 5:
			break
		print(i)
```
```out
1
3
5
```
Чётные пропущены (`continue`), а на 7 цикл закончился (`break`).

:: quiz
Когда использовать `while`, а когда `for`?
[x] `for` — когда известно, по чему идти; `while` — пока выполняется условие => Верно.
[ ] Всегда `while`, он мощнее => Можно, но `for` проще и безопаснее: он не зависнет.
[ ] Это одно и то же => Нет: `for` идёт по списку, `while` проверяет условие.

:: recap
- `while условие:` — повторять, пока условие верно. Следи, чтобы оно стало ложным.
- `break` — выйти из цикла, `continue` — к следующему шагу.

## LESSON m06-p | Практика: инвентарь | 10 | practice
:: goals
- Массивы, циклы и условия вместе

:: task
Перед тобой список монет, собранных на уровнях: `[3, 0, 7, 2, 0, 5]`. Посчитай:
- сколько всего монет;
- на скольких уровнях монет не было (0).

Напечатай:
```text
Монет: 17
Пустых уровней: 2
```
```gd
extends Node

func _ready():
	var coins = [3, 0, 7, 2, 0, 5]
```
```solution
extends Node

func _ready():
	var coins = [3, 0, 7, 2, 0, 5]
	var total = 0
	var empty = 0
	for c in coins:
		total += c
		if c == 0:
			empty += 1
	print("Монет: ", total)
	print("Пустых уровней: ", empty)
```
```expect
Монет: 17
Пустых уровней: 2
```
hint: Нужно две переменные-счётчика до цикла: `total` и `empty`.
hint: Внутри цикла: `total += c`, а если `c == 0` — `empty += 1`.

:: task
Найди самое большое число в списке очков `[40, 95, 12, 77]`, не используя готовых функций. Напечатай:
```text
Рекорд: 95
```
```gd
extends Node

func _ready():
	var scores = [40, 95, 12, 77]
	var best = scores[0]
```
```solution
extends Node

func _ready():
	var scores = [40, 95, 12, 77]
	var best = scores[0]
	for s in scores:
		if s > best:
			best = s
	print("Рекорд: ", best)
```
```expect
Рекорд: 95
```
hint: Сначала считаем рекордом первый элемент. Потом идём по всем.
hint: Если текущее число больше рекорда — оно становится новым рекордом: `best = s`.

:: deep Готовые функции и лямбды
У массива есть готовый метод `max()`: `scores.max()` вернёт 95. Самому написать поиск полезно, чтобы понять, как это работает.

Ещё у массива есть методы, которые принимают **функцию**: `filter` (отобрать), `map` (превратить каждый). Короткая безымянная функция называется **лямбдой**: `func(x): return x > 50`.
```gd
extends Node

func _ready():
	var scores = [40, 95, 12, 77]
	print(scores.max())
	print(scores.filter(func(s): return s > 50))
	print(scores.map(func(s): return s * 2))
```
```out
95
[95, 77]
[80, 190, 24, 154]
```

:: recap
- Счётчик заводят до цикла, а меняют внутри.
- Поиск рекорда: взять первый элемент и сравнивать с каждым следующим.
