# MODULE m13 | Сигналы | Как узлы сообщают друг другу о событиях

## LESSON m13-1 | Что такое сигнал | 7
:: goals
- Что такое сигнал
- Кто его отправляет и кто получает

:: text Узел кричит «случилось!»
visual: concept-m13
**Сигнал** (signal) — сообщение, которое узел отправляет, когда что-то произошло:

- кнопка `Button` отправляет `pressed` — «меня нажали»;
- зона `Area2D` отправляет `body_entered` — «в меня кто-то вошёл»;
- таймер `Timer` отправляет `timeout` — «время вышло».

Другой узел может **подключиться** к сигналу и сказать: «когда это случится — вызови мою функцию».

**Аналогия:** дверной звонок. Кнопка звонка не знает, кто в доме и что он будет делать. Она просто звенит. А хозяин слышит звонок и решает: открыть дверь.

:: text Зачем это нужно
Без сигналов монетке пришлось бы знать про счёт, звук, интерфейс и сохранение. С сигналами монетка просто сообщает «меня подобрали». А кто и как на это реагирует — не её забота.

Узлы получаются **независимыми**. Монетку можно перенести в другую игру — она будет работать.

Правило Godot: **сигналы идут вверх, вызовы функций — вниз**. Родитель вызывает функции детей. Дети сообщают родителю сигналами.

:: quiz
Какой сигнал отправляет кнопка, когда на неё нажали?
[x] `pressed` => Верно.
[ ] `timeout` => Это сигнал таймера.
[ ] `body_entered` => Это сигнал зоны Area2D.

:: recap
- **Сигнал** — сообщение «произошло событие».
- К сигналу **подключают** функцию — она вызовется, когда сигнал придёт.
- Сигналы делают узлы независимыми. Сигналы — вверх, вызовы — вниз.

## LESSON m13-2 | Подключение в редакторе | 7
:: goals
- Как подключить сигнал мышкой
- Как называется функция-получатель

:: steps Кнопка, которая отвечает
visual: guide-m13-2-0
Открой `main.tscn`. У корня `Main` есть скрипт.
- Добавь в `Main` ребёнка **Button**. В Инспекторе в **Text** напиши `Нажми меня`.
- Выбери `Button`. Справа рядом с **Inspector** открой вкладку **Signals** (Сигналы). В некоторых версиях Godot 4 она находится внутри вкладки **Node** (Узел).
- Найди в списке `pressed()` и дважды кликни по нему.
- Откроется окно. Выбери узел `Main` (туда придёт сигнал). Имя функции Godot предложит сам: `_on_button_pressed`. Нажми **Connect**.
- В `main.gd` появилась новая функция с зелёной иконкой слева. Напиши в ней `print("Нажали!")` вместо `pass`.
- Нажми `F6` и покликай по кнопке. Смотри в панель **Output**.

:: text Имя функции
Godot называет функцию так: `_on_` + имя узла + `_` + имя сигнала.

- узел `Button`, сигнал `pressed` → `_on_button_pressed`;
- узел `Coin`, сигнал `body_entered` → `_on_coin_body_entered`.

Имя можно поменять, но такой порядок удобен: сразу видно, откуда сигнал.

Зелёная иконка слева от функции значит «сюда подключён сигнал». По ней можно кликнуть и посмотреть откуда.

:: quiz
Сигнал `timeout` узла `SpawnTimer` подключили к скрипту. Какое имя функции предложит Godot?
[ ] `timeout_spawn_timer` => Порядок другой: сначала `_on_`, потом узел, потом сигнал.
[x] `_on_spawn_timer_timeout` => Верно.
[ ] `_ready` => `_ready` — встроенная функция, сигналы туда не подключают.

:: recap
- Подключить в редакторе: вкладка **Node → Signals**, двойной клик по сигналу, **Connect**.
- Имя функции: `_on_<узел>_<сигнал>`.
- Зелёная иконка у функции — к ней подключён сигнал.

## LESSON m13-3 | Подключение в коде | 8
:: goals
- Как подключить сигнал строкой кода
- Как сигнал передаёт данные

:: text connect
Сигнал можно подключить и в коде. Это удобно, когда узлы создаются во время игры.

```gd
$Button.pressed.connect(_on_button_pressed)
```

Читается: «у кнопки возьми сигнал `pressed` и подключи (`connect`) к функции `_on_button_pressed`».

!> Имя функции пишут **без скобок**. Со скобками `_on_button_pressed()` функция вызовется сразу, а подключать будет нечего.

:: code
В тренажёре кнопку нельзя нажать мышкой. Но можно отправить её сигнал вручную: `emit()` — «отправить».
```gd
extends Node

func _ready():
	var button = Button.new()
	add_child(button)
	button.pressed.connect(_on_button_pressed)
	button.pressed.emit()
	button.pressed.emit()

func _on_button_pressed():
	print("Нажали!")
```
```out
Нажали!
Нажали!
```
Сигнал отправили два раза — функция сработала два раза.

:: text Сигнал с данными
Некоторые сигналы передают данные. Например, `body_entered(body)` сообщает, **кто** вошёл в зону. Функция-получатель принимает это как параметр:

```gd
func _on_coin_body_entered(body):
	if body.name == "Player":
		print("Игрок взял монетку")
```

:: code
Таймер — хороший пример для тренажёра. Он отправляет `timeout` каждые `wait_time` секунд.
```gd
extends Node
# тренажёр: кадров=6 дельта=0.5

var ticks = 0

func _ready():
	var timer = Timer.new()
	timer.wait_time = 1.0
	add_child(timer)
	timer.timeout.connect(_on_timer_timeout)
	timer.start()

func _on_timer_timeout():
	ticks += 1
	print("Прошла секунда, тиков: ", ticks)
```
```out
Прошла секунда, тиков: 1
Прошла секунда, тиков: 2
Прошла секунда, тиков: 3
```
6 кадров по 0.5 с = 3 секунды. Таймер сработал 3 раза.

:: fill
Подключи сигнал `timeout` таймера к функции `_on_timeout`.
```gd
extends Node

func _ready():
	var t = Timer.new()
	add_child(t)
	t.___.connect(___)

func _on_timeout():
	print("Время!")
```
= timeout
= _on_timeout
explain: Имя функции — без скобок: мы передаём саму функцию, а не вызываем её.

:: recap
- `узел.сигнал.connect(функция)` — подключить в коде. Функция без скобок.
- `узел.сигнал.emit()` — отправить сигнал.
- Данные сигнала приходят в параметры функции: `func _on_x(body):`.

## LESSON m13-4 | Свои сигналы | 8
:: goals
- Как объявить свой сигнал
- Как отправить его с данными

:: text signal
Свой сигнал объявляют вверху скрипта словом `signal`:

```gd
signal died
signal health_changed(new_health)
```

Отправляют через `emit()`. Данные — в скобках:

```gd
died.emit()
health_changed.emit(health)
```

:: code
Игрок сообщает об изменении здоровья и о смерти. Он не знает, кто его слушает. Слушать может интерфейс, звук, счётчик — кто угодно.
```gd
extends Node

signal health_changed(value)
signal died

var health = 3

func _ready():
	health_changed.connect(_on_health_changed)
	died.connect(_on_died)
	for i in 3:
		take_damage(1)

func take_damage(amount):
	health -= amount
	health_changed.emit(health)
	if health <= 0:
		died.emit()

func _on_health_changed(value):
	print("Здоровье: ", value)

func _on_died():
	print("Игрок погиб")
```
```out
Здоровье: 2
Здоровье: 1
Здоровье: 0
Игрок погиб
```

:: text Сигналы между разными узлами
Обычно сигнал объявляют в одном скрипте, а слушают в другом. Например, у врага:

```gd
# enemy.gd
signal killed(points)
```

А в уровне:

```gd
# level.gd
func _ready():
	$Enemy.killed.connect(_on_enemy_killed)

func _on_enemy_killed(points):
	score += points
```

Свои сигналы тоже видны во вкладке **Node → Signals** и подключаются мышкой.

:: task
У сундука есть сигнал `opened(gold)`. Подключи его к функции `_on_chest_opened`, которая прибавляет золото к `total_gold` и печатает `Золото: X`. Потом открой сундук два раза — с 50 и с 25 золота:
```text
Золото: 50
Золото: 75
```
```gd
extends Node

signal opened(gold)

var total_gold = 0

func _ready():
	# подключи сигнал
	# отправь сигнал два раза: 50 и 25
	pass

func _on_chest_opened(gold):
	pass
```
```solution
extends Node

signal opened(gold)

var total_gold = 0

func _ready():
	opened.connect(_on_chest_opened)
	opened.emit(50)
	opened.emit(25)

func _on_chest_opened(gold):
	total_gold += gold
	print("Золото: ", total_gold)
```
```expect
Золото: 50
Золото: 75
```
hint: Подключение: `opened.connect(_on_chest_opened)`.
hint: Отправка с данными: `opened.emit(50)`.

:: recap
- `signal имя(параметры)` — объявить свой сигнал.
- `имя.emit(данные)` — отправить.
- Тот, кто отправляет, не знает, кто слушает. Это и делает код гибким.
