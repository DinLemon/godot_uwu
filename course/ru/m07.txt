# MODULE m07 | Функции | Свои команды с именем

## LESSON m07-1 | Своя функция | 7
:: goals
- Что такое функция
- Как её объявить и вызвать

:: text Функция — рецепт с именем
visual: concept-m07
**Функция** — кусок кода с именем. Написал один раз — вызываешь сколько угодно раз.

**Аналогия:** рецепт. Записал «как сварить кашу» один раз. Потом просто говоришь «свари кашу».

Ты уже пользовался чужими функциями: `print()`, `str()`, `range()`. И уже писал свою: `_ready()`.

:: text Как объявить
```gd
func say_hello():
	print("Привет!")
```

- `func` — «сейчас будет функция»;
- `say_hello` — имя (в snake_case);
- `()` — скобки для параметров (пока пустые);
- `:` и блок с отступом — тело функции.

Чтобы функция сработала, её надо **вызвать**: написать имя со скобками `say_hello()`.

:: code
Функции пишут на верхнем уровне скрипта — без отступа, рядом с `_ready`. А вызывают изнутри других функций.
```gd
extends Node

func _ready():
	say_hello()
	say_hello()
	print("Готово")

func say_hello():
	print("Привет!")
```
```out
Привет!
Привет!
Готово
```
Порядок функций в файле не важен. `_ready` может вызвать функцию, которая написана ниже.

:: code
Нельзя объявлять функцию внутри другой функции. Запусти.
```gd
extends Node

func _ready():
	func greet():
		print("Привет")
	greet()
```
fails: yes
Каждая `func` начинается с самого левого края, без отступа.

:: quiz
Что произойдёт, если объявить функцию, но ни разу её не вызвать?
[ ] Она выполнится сама один раз => Сама выполнится только `_ready` и другие функции, которые вызывает Godot.
[x] Ничего: код внутри не выполнится => Верно. Рецепт записан, но никто не готовит.
[ ] Будет ошибка => Ошибки нет, просто функция не используется.

:: recap
- `func имя():` — объявить функцию. Тело — с отступом.
- `имя()` — вызвать функцию.
- Функции пишутся без отступа, на верхнем уровне скрипта.

## LESSON m07-2 | Параметры | 7
:: goals
- Как передать в функцию данные
- Несколько параметров
- Значения по умолчанию

:: text Параметры — входящие данные
Функция становится полезнее, если ей можно что-то передать. Например, **сколько** урона нанести.

```gd
func take_damage(amount):
	print("Получено урона: ", amount)
```

`amount` — **параметр**. Это переменная, которая получит значение при вызове:

```gd
take_damage(10)   # amount = 10
take_damage(25)   # amount = 25
```

Значение при вызове называют **аргументом**.

:: code
Параметров может быть несколько — через запятую. Порядок важен.
```gd
extends Node

func _ready():
	greet("Аня", 3)
	greet("Борис", 7)

func greet(who, level):
	print(who, " (уровень ", level, ") входит в игру")
```
```out
Аня (уровень 3) входит в игру
Борис (уровень 7) входит в игру
```

:: text Значение по умолчанию
Параметру можно дать значение по умолчанию. Тогда при вызове его можно не писать:

```gd
func heal(amount = 10):
	print("Лечение +", amount)

heal()     # Лечение +10
heal(50)   # Лечение +50
```

:: code
Если передать не то количество аргументов, будет ошибка.
```gd
extends Node

func _ready():
	greet("Аня")

func greet(who, level):
	print(who, level)
```
fails: yes
Godot прямо говорит: ожидалось минимум 2, получено 1.

:: fill
Допиши функцию, чтобы `shout("ура")` печатала `УРА!`.
```gd
extends Node

func _ready():
	shout("ура")

func shout(___):
	print(text.to_upper() + "!")
```
= text
explain: Имя параметра должно совпадать с тем, что используется внутри: `text`. А `to_upper()` делает буквы большими.

:: recap
- Параметры пишут в скобках: `func f(a, b):`.
- При вызове передают аргументы в том же порядке: `f(1, 2)`.
- Значение по умолчанию: `func heal(amount = 10):`.

## LESSON m07-3 | return — результат функции | 8
:: goals
- Как функция возвращает ответ
- Чем `return` отличается от `print`

:: text Функция может ответить
Иногда функция должна не напечатать, а **посчитать** и отдать результат. Для этого `return` («верни»):

```gd
func double(x):
	return x * 2

var a = double(5)   # a = 10
```

Вызов `double(5)` превращается в значение 10. Его можно положить в переменную, напечатать или передать дальше.

:: text print и return — разные вещи
- `print` показывает текст **тебе** в Output. Программа это значение не получает.
- `return` отдаёт значение **программе**. Сам по себе ничего не печатает.

После `return` функция сразу заканчивается. Строки ниже не выполнятся.

:: code
```gd
extends Node

func _ready():
	var hp = 100
	hp = apply_damage(hp, 30)
	print(hp)
	print(is_dead(hp))
	print(is_dead(apply_damage(hp, 90)))

func apply_damage(health, dmg):
	return health - dmg

func is_dead(health):
	return health <= 0
```
```out
70
false
true
```
Результат одной функции можно сразу передать в другую.

:: text Ранний выход
`return` без значения просто завершает функцию. Удобно для проверок в начале:

```gd
func shoot():
	if ammo == 0:
		return          # патронов нет — выходим
	ammo -= 1
	print("Бах!")
```

:: quiz
Что напечатает код?
```gd
func f():
	return 5
	print("после")

func _ready():
	print(f())
```
[x] `5` => Верно. После `return` функция закончилась, строка «после» не выполнилась.
[ ] `после` и `5` => `print("после")` стоит после `return` — до него дело не дойдёт.
[ ] Ничего => `print(f())` напечатает то, что вернула функция.

:: task
Напиши функцию `max_of(a, b)`, которая **возвращает** большее из двух чисел. В `_ready` уже есть проверка — она должна напечатать:
```text
8
3
```
```gd
extends Node

func _ready():
	print(max_of(8, 2))
	print(max_of(-1, 3))

func max_of(a, b):
	pass
```
```solution
extends Node

func _ready():
	print(max_of(8, 2))
	print(max_of(-1, 3))

func max_of(a, b):
	if a > b:
		return a
	return b
```
```expect
8
3
```
hint: Сравни `a` и `b` через `if`.
hint: Внутри функции нужен `return`, а не `print`. Печатает уже `_ready`.

:: recap
- `return значение` — отдать результат и выйти из функции.
- `print` показывает, `return` отдаёт программе.
- Результат вызова можно положить в переменную: `var x = f()`.

## LESSON m07-4 | Типы в функциях и видимость | 7
:: goals
- Как указать типы параметров и результата
- Что значит `-> void`
- Где «видна» переменная

:: text Типы параметров
Как и у переменных, у параметров можно указать тип. А после `->` — тип результата:

```gd
func apply_damage(health: int, dmg: int) -> int:
	return health - dmg
```

`-> void` значит «функция ничего не возвращает». Помнишь заготовку Godot `func _ready() -> void:`? Теперь понятно, что это.

Типы помогают: Godot подсветит ошибку, если передать текст вместо числа.

:: code
```gd
extends Node

func _ready():
	print(area(3, 4))
	print(area(2.5, 2))

func area(w: float, h: float) -> float:
	return w * h
```
```out
12.0
5.0
```
Целое `3` превратилось в дробное `3.0`, потому что параметр типа `float`.

:: text Переменная живёт в своём блоке
Переменная, созданная внутри функции, **видна только внутри этой функции**. Это называется областью видимости.

Если переменная нужна нескольким функциям — объяви её **вверху скрипта**, вне функций. Такие переменные называются **переменными скрипта** (или полями узла).

```gd
extends Node

var score = 0          # видна во всём скрипте

func _ready():
	add_points(5)
	print(score)       # 5

func add_points(n):
	var bonus = 1      # видна только здесь
	score += n
```

:: code
Здесь `coins` создана в `_ready`, а другая функция пытается ей пользоваться.
```gd
extends Node

func _ready():
	var coins = 10
	spend()

func spend():
	coins -= 1
```
fails: yes
Исправь так: перенеси `var coins = 10` наверх, под `extends Node`, без отступа.

:: quiz
Где объявить переменную `score`, чтобы её видели все функции скрипта?
[ ] Внутри `_ready` => Тогда её увидит только `_ready`.
[x] Вверху скрипта, вне функций => Верно. Это переменная скрипта.
[ ] В каждой функции заново => Это будут разные переменные с одинаковым именем.

:: recap
- `func f(a: int) -> int:` — типы параметров и результата.
- `-> void` — функция ничего не возвращает.
- Переменная из функции видна только в ней. Общие переменные — вверху скрипта.

## LESSON m07-p | Практика: система урона | 10 | practice
:: goals
- Переменные скрипта, функции, условия и return вместе

:: task
Сделай маленькую систему здоровья.
- Вверху скрипта: `var health = 100`.
- Функция `hit(dmg)` отнимает урон и печатает `Здоровье: X`. Здоровье не может стать меньше 0.
- Функция `is_alive()` возвращает `true`, если здоровье больше 0.

`_ready` уже написан. Должно напечататься:
```text
Здоровье: 60
Здоровье: 0
false
```
```gd
extends Node

var health = 100

func _ready():
	hit(40)
	hit(80)
	print(is_alive())

# напиши функции hit и is_alive
```
```solution
extends Node

var health = 100

func _ready():
	hit(40)
	hit(80)
	print(is_alive())

func hit(dmg):
	health -= dmg
	if health < 0:
		health = 0
	print("Здоровье: ", health)

func is_alive():
	return health > 0
```
```expect
Здоровье: 60
Здоровье: 0
false
```
hint: В `hit`: сначала `health -= dmg`, потом проверка `if health < 0: health = 0`.
hint: `is_alive` — одна строка: `return health > 0`.
hint: Есть встроенная функция `max(a, b)`: `health = max(health - dmg, 0)` — делает то же самое короче.

:: deep Функция вызывает сама себя
Функция может вызвать сама себя. Это называется **рекурсией**. Главное — условие остановки, иначе вызовы будут бесконечными.

Пример: факториал. 5! = 5 × 4 × 3 × 2 × 1.
```gd
extends Node

func _ready():
	print(factorial(5))

func factorial(n):
	if n <= 1:
		return 1
	return n * factorial(n - 1)
```
```out
120
```

:: recap
- Состояние (здоровье) — переменная скрипта.
- Действия (получить урон) — функции, которые меняют состояние.
- Вопросы (жив ли?) — функции, которые возвращают bool.
