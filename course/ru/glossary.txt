// термин | английский | объяснение
Движок | game engine | Программа с готовыми инструментами для создания игр: рисует картинку, играет звук, считает физику. Godot — игровой движок.
Проект | project | Папка с игрой. В ней лежит файл `project.godot` и все картинки, сцены, скрипты.
Узел | node | Главный кирпичик Godot. У каждого узла одна задача: показать картинку, проиграть звук, посчитать время.
Сцена | scene | Дерево узлов, сохранённое в файл `.tscn`. Персонаж, монетка, уровень — отдельные сцены.
Дерево сцены | scene tree | Узлы, вложенные друг в друга, как папки. Сверху — корень.
Корневой узел | root node | Самый верхний узел дерева сцены. У дерева он один.
Родитель | parent | Узел, внутри которого лежит другой узел. Дети двигаются вместе с родителем.
Ребёнок | child | Узел, вложенный в другой узел.
Свойство | property | Настройка узла: позиция, цвет, текст. Видна в Инспекторе.
Инспектор | Inspector | Панель справа в редакторе. Показывает свойства выбранного узла.
Главная сцена | main scene | Сцена, с которой начинается игра по `F5`.
Экземпляр | instance | Копия сцены внутри другой сцены. Монеток на уровне много, а сцена монетки одна.
Скрипт | script | Текст с командами на GDScript. Прикрепляется к узлу и управляет им. Файл `.gd`.
GDScript | GDScript | Язык программирования Godot. Простой, похож на Python.
Переменная | variable | Коробка с именем, в которой лежит значение. Создаётся словом `var`.
Константа | constant | Значение, которое нельзя поменять. Создаётся словом `const`, имя пишут БОЛЬШИМИ буквами.
Тип | type | Вид данных: целое число `int`, дробное `float`, текст `String`, да/нет `bool` и другие.
Целое число | int | Число без дробной части: `5`, `-3`, `100`.
Дробное число | float | Число с точкой: `2.5`, `0.1`, `9.81`.
Строка | String | Текст в кавычках: `"Привет"`.
Логический тип | bool | Тип с двумя значениями: `true` (правда) и `false` (ложь).
Подсказка типа | type hint | Тип, указанный после имени: `var hp: int = 5`. Помогает Godot ловить ошибки.
Комментарий | comment | Текст после `#`. Godot его пропускает. Записка для людей.
Отступ | indentation | Сдвиг строки вправо (`Tab`). Показывает, что строка лежит внутри `func`, `if`, `for`.
Блок | block | Строки с одинаковым отступом под строкой с двоеточием.
Условие | condition | Вопрос с ответом да/нет: `hp > 0`. Используется в `if` и `while`.
Цикл | loop | Повторение блока кода: `for` (для каждого) или `while` (пока).
Массив | Array | Список значений в квадратных скобках: `[1, 2, 3]`. Номера идут с нуля.
Индекс | index | Номер элемента в массиве. Первый элемент — номер 0.
Словарь | Dictionary | Пары «ключ → значение» в фигурных скобках: `{"hp": 10}`.
Ключ | key | Подпись значения в словаре.
Функция | function | Кусок кода с именем. Объявляется через `func`, вызывается по имени со скобками.
Параметр | parameter | Переменная функции, которая получает значение при вызове: `func heal(amount):`.
Аргумент | argument | Значение, которое передают в функцию при вызове: `heal(10)`.
Возвращаемое значение | return value | Результат функции, который отдаёт `return`.
Метод | method | Функция, которая принадлежит объекту: `массив.append(5)`.
Область видимости | scope | Место в коде, где видна переменная. Переменная из функции видна только в ней.
Кадр | frame | Одна картинка игры. Обычно 60 кадров в секунду.
delta | delta | Сколько секунд прошло с прошлого кадра. На неё умножают скорость.
_ready | _ready | Функция, которую Godot вызывает один раз, когда узел появился в игре.
_process | _process | Функция, которую Godot вызывает каждый кадр.
_physics_process | _physics_process | Как `_process`, но для физики: 60 раз в секунду с одинаковой `delta`.
Экспорт переменной | @export | Пометка, после которой переменная видна и меняется в Инспекторе.
Путь к узлу | NodePath | Адрес узла в дереве: `$Body/Sprite2D`. `..` значит «на уровень вверх».
@onready | @onready | Пометка: заполнить переменную, когда узел готов (перед `_ready`).
Вектор | Vector2 | Пара чисел x и y. Позиция, скорость, направление в 2D.
Нормализация | normalize | Сделать вектор длиной 1, сохранив направление. `normalized()`.
Трансформация | transform | Позиция, поворот и масштаб узла вместе.
Радиан | radian | Единица угла. Полный круг — около 6.28 (TAU). 90° — около 1.57.
Действие | action | Имя для управления (`jump`), к которому привязаны клавиши. Настраивается в Input Map.
Input Map | Input Map | Вкладка в настройках проекта со списком действий и их клавиш.
Тело | body | Физический объект: StaticBody2D, CharacterBody2D, RigidBody2D.
Форма столкновения | CollisionShape2D | Узел с формой (прямоугольник, круг) для физики. Нужен каждому телу и зоне.
Зона | Area2D | Узел, который замечает, кто в него вошёл, но не мешает движению.
Скорость | velocity | Вектор скорости персонажа в пикселях в секунду. Для CharacterBody2D.
Гравитация | gravity | Ускорение вниз. Каждую секунду добавляет скорость падения.
Слой столкновений | collision layer | На каком «этаже» находится тело.
Маска столкновений | collision mask | С какими «этажами» тело сталкивается.
Сигнал | signal | Сообщение узла «что-то произошло». К нему подключают функции.
Подключение | connect | Связь сигнала с функцией: когда сигнал придёт, функция вызовется.
emit | emit | Отправить сигнал: `died.emit()`.
PackedScene | PackedScene | Загруженный «чертёж» сцены. Из него `instantiate()` делает экземпляр.
preload | preload | Загрузить файл (сцену, картинку) заранее: `preload("res://coin.tscn")`.
queue_free | queue_free | Удалить узел в конце кадра вместе со всеми детьми.
Группа | group | Ярлык для узлов: `enemies`, `coins`. Позволяет найти все узлы с ярлыком.
Спрайт | sprite | Картинка в игре. Узел Sprite2D.
Спрайтшит | spritesheet | Одна картинка, на которой сеткой нарисованы все кадры анимации.
Ключевой кадр | keyframe | Точка в анимации: «в это время свойство такое». Между ключами Godot считает сам.
Tween | Tween | Короткая анимация свойства прямо из кода.
Камера | Camera2D | Узел, через который смотрим на мир. Показывает часть мира вокруг себя.
Тайл | tile | Плитка, из которых собирают уровень, обычно 16×16 или 32×32 пикселя.
TileSet | TileSet | Набор плиток и их свойства: столкновения, тип.
TileMapLayer | TileMapLayer | Узел-слой, на котором плитками нарисован уровень.
Интерфейс | UI | Всё, что поверх игры: счёт, кнопки, меню. Узлы-наследники Control.
Якорь | anchor | Привязка элемента интерфейса к краю или центру окна.
Контейнер | container | Узел интерфейса, который сам раскладывает детей: в строку, столбиком, сеткой.
HUD | HUD | Интерфейс поверх игры во время игры: здоровье, счёт, таймер.
CanvasLayer | CanvasLayer | Слой поверх игры, который не двигается с камерой.
Таймер | Timer | Узел, который отсчитывает время и отправляет сигнал `timeout`.
await | await | «Дождись»: ставит функцию на паузу до сигнала.
Автозагрузка | Autoload | Скрипт или сцена, которые живут всю игру и не удаляются при смене сцен.
Синглтон | singleton | Объект, который существует в одном экземпляре на всю игру. Например, Autoload.
Класс | class | Чертёж объектов. Каждый скрипт — класс.
Объект | object | Экземпляр класса со своими значениями.
Конструктор | _init | Функция, которая вызывается при создании объекта через `new()`.
Наследование | inheritance | Класс на основе другого: получает всё от родителя и добавляет своё. `extends`.
Переопределение | override | Функция в наследнике с тем же именем, что у родителя. Заменяет её.
Ресурс | Resource | Объект с данными, который можно сохранить в файл `.tres`.
Перечисление | enum | Набор именованных вариантов: `enum State { IDLE, RUN }`.
Машина состояний | state machine | Приём: персонаж всегда в одном состоянии (стоит, бежит, прыгает), а правила говорят, когда переходить в другое.
JSON | JSON | Текстовый формат для данных. Похож на словари GDScript.
res:// | res:// | Папка проекта. В готовой игре — только для чтения.
user:// | user:// | Папка игры на компьютере игрока. Сюда сохраняют прогресс и настройки.
Точка останова | breakpoint | Красная точка у строки кода: игра остановится на ней, и можно посмотреть переменные.
Отладка | debugging | Поиск и исправление ошибок.
Экспорт | export | Сборка проекта в готовую игру, которая запускается без Godot.
Шаблоны экспорта | export templates | Файлы движка под каждую систему. Нужны для экспорта, скачиваются один раз.
Рендерер | renderer | Способ, которым Godot рисует картинку: Forward+, Mobile, Compatibility.
itch.io | itch.io | Бесплатная площадка, где выкладывают инди-игры, в том числе для браузера.
Game jam | game jam | Соревнование: сделать игру за короткий срок, обычно 48 часов.
