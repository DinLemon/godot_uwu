# MODULE m08 | Словари и строки | Данные с подписями и работа с текстом

## LESSON m08-1 | Словарь — данные с подписями | 7
:: goals
- Что такое словарь
- Как достать и поменять значение по ключу

:: text Ключ и значение
В массиве элементы стоят по номерам. Но иногда номер ничего не говорит. Что такое `hero[2]`? Здоровье? Скорость?

**Словарь** (Dictionary) хранит пары **ключ → значение**. Ключ — подпись, значение — то, что под ней лежит.

```gd
var hero = {
	"name": "Рыцарь",
	"hp": 100,
	"speed": 150,
}
```

Пишется в фигурных скобках `{ }`. Ключ и значение разделяет двоеточие, пары — запятые.

**Аналогия:** анкета. Слева графа «Имя», справа ответ «Рыцарь».

:: code
Значение берут по ключу в квадратных скобках. Так же его меняют или добавляют новое.
```gd
extends Node

func _ready():
	var hero = {"name": "Рыцарь", "hp": 100}
	print(hero["name"])
	hero["hp"] -= 30
	hero["level"] = 2
	print(hero)
```
```out
Рыцарь
{ "name": "Рыцарь", "hp": 70, "level": 2 }
```
Если ключа нет, `hero["level"] = 2` его создаёт.

:: code
Взять несуществующий ключ — ошибка. Запусти.
```gd
extends Node

func _ready():
	var hero = {"name": "Рыцарь"}
	print(hero["mana"])
```
fails: yes
Безопасные способы: проверить `hero.has("mana")` или взять с запасным значением `hero.get("mana", 0)`.

:: quiz
`var prices = {"меч": 50, "лук": 40}`. Что вернёт `prices.get("щит", 0)`?
[ ] Ошибку => `get` с запасным значением не падает.
[x] `0` => Верно. Ключа «щит» нет, поэтому вернётся запасное значение.
[ ] `null` => `null` был бы, если не указать запасное значение.

:: recap
- Словарь: `{"ключ": значение, ...}`.
- `d["ключ"]` — взять или записать значение.
- `d.has("ключ")` — есть ли ключ. `d.get("ключ", запас)` — взять без ошибки.

## LESSON m08-2 | Перебор словаря | 7
:: goals
- Как пройти по всем парам словаря
- Методы `keys`, `values`, `erase`, `size`

:: code
`for` по словарю перебирает **ключи**. Значение достаём по ключу.
```gd
extends Node

func _ready():
	var stock = {"зелье": 3, "стрела": 20, "ключ": 1}
	for item in stock:
		print(item, ": ", stock[item])
```
```out
зелье: 3
стрела: 20
ключ: 1
```
Ключи идут в том порядке, в каком их добавляли.

:: code
Полезные методы словаря.
```gd
extends Node

func _ready():
	var stock = {"зелье": 3, "стрела": 20}
	print(stock.keys())
	print(stock.values())
	print(stock.size())
	stock.erase("зелье")
	print(stock)
	print("стрела" in stock)
```
```out
["зелье", "стрела"]
[3, 20]
2
{ "стрела": 20 }
true
```

:: task
Посчитай, сколько всего предметов в инвентаре (сумма всех значений). Напечатай:
```text
Всего предметов: 24
```
```gd
extends Node

func _ready():
	var stock = {"зелье": 3, "стрела": 20, "ключ": 1}
```
```solution
extends Node

func _ready():
	var stock = {"зелье": 3, "стрела": 20, "ключ": 1}
	var total = 0
	for item in stock:
		total += stock[item]
	print("Всего предметов: ", total)
```
```expect
Всего предметов: 24
```
hint: Как с массивом: счётчик до цикла, прибавляем внутри.
hint: Внутри цикла значение — `stock[item]`. Или перебирай сразу `stock.values()`.

:: recap
- `for key in словарь:` перебирает ключи.
- `keys()`, `values()`, `size()`, `erase(ключ)`, `in`.

## LESSON m08-3 | Работа со строками | 7
:: goals
- Полезные методы строк
- Как разбить строку на части и собрать обратно

:: text Строка тоже умеет многое
У строк много методов. Самые нужные:

- `length()` — длина;
- `to_upper()`, `to_lower()` — БОЛЬШИЕ / маленькие буквы;
- `contains("x")` — есть ли кусок текста;
- `begins_with("x")`, `ends_with("x")` — начинается / заканчивается ли;
- `replace("что", "на что")` — заменить;
- `split(",")` — разрезать в массив по разделителю;
- `strip_edges()` — убрать пробелы по краям.

Строку можно читать по буквам, как массив: `"кот"[0]` — это `"к"`.

:: code
```gd
extends Node

func _ready():
	var s = "  Привет, мир  "
	var t = s.strip_edges()
	print(t.length())
	print(t.to_upper())
	print(t.contains("мир"))
	print(t.replace("мир", "Godot"))
	print("меч,щит,лук".split(","))
	print(t[0])
```
```out
11
ПРИВЕТ, МИР
true
Привет, Godot
["меч", "щит", "лук"]
П
```

:: text Строки нельзя менять «на месте»
Методы строки **не меняют** исходную строку. Они возвращают новую.

```gd
var a = "кот"
a.to_upper()       # результат никуда не сохранили
print(a)           # кот
a = a.to_upper()   # вот так — сохранили
print(a)           # КОТ
```

:: fill
Разрежь строку с очками на части по пробелу.
```gd
extends Node

func _ready():
	var line = "10 20 30"
	var parts = line.___(" ")
	print(parts.size())
```
= split
explain: `split(" ")` вернёт массив `["10", "20", "30"]`, в нём 3 элемента.

:: task
В строке `"Аня:120"` записаны имя и очки. В выходные очки удваиваются. Достань имя и очки и напечатай:
```text
Аня: 240 очков
```
```gd
extends Node

func _ready():
	var record = "Аня:120"
```
```solution
extends Node

func _ready():
	var record = "Аня:120"
	var parts = record.split(":")
	var player = parts[0]
	var points = int(parts[1])
	print(player, ": ", points * 2, " очков")
```
```expect
Аня: 240 очков
```
hint: `record.split(":")` вернёт массив `["Аня", "120"]`.
hint: `"120"` — это текст. Умножить его на 2 нельзя. Сначала `int(parts[1])`.

:: recap
- `length`, `to_upper`, `contains`, `replace`, `split`, `strip_edges`.
- Методы строк возвращают **новую** строку — сохраняй результат.
- `int("12")` и `float("1.5")` превращают текст в число.

## LESSON m08-p | Практика: магазин | 10 | practice
:: goals
- Словари, массивы, функции и условия вместе

:: task
В магазине цены: `{"меч": 50, "щит": 40, "зелье": 15}`. У игрока 70 монет.

Напиши функцию `buy(item)`:
- если такого товара нет — печатает `Нет товара: X`;
- если денег не хватает — печатает `Мало денег на X`;
- иначе отнимает цену и печатает `Куплено: X, осталось Y`.

Должно получиться:
```text
Куплено: меч, осталось 20
Мало денег на щит
Нет товара: лук
Куплено: зелье, осталось 5
```
```gd
extends Node

var prices = {"меч": 50, "щит": 40, "зелье": 15}
var money = 70

func _ready():
	buy("меч")
	buy("щит")
	buy("лук")
	buy("зелье")

func buy(item):
	pass
```
```solution
extends Node

var prices = {"меч": 50, "щит": 40, "зелье": 15}
var money = 70

func _ready():
	buy("меч")
	buy("щит")
	buy("лук")
	buy("зелье")

func buy(item):
	if not prices.has(item):
		print("Нет товара: ", item)
		return
	var price = prices[item]
	if money < price:
		print("Мало денег на ", item)
		return
	money -= price
	print("Куплено: ", item, ", осталось ", money)
```
```expect
Куплено: меч, осталось 20
Мало денег на щит
Нет товара: лук
Куплено: зелье, осталось 5
```
hint: Первой проверкой убедись, что товар есть: `prices.has(item)`.
hint: После печати ошибки делай `return`, чтобы не идти дальше.
hint: Цена — `prices[item]`. Денег хватает, если `money >= price`.

:: recap
- Словарь удобно хранит «название → цена» или «предмет → количество».
- Проверки с ранним `return` делают функцию простой для чтения.
