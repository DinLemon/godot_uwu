# MODULE m05 | Условия | Игра принимает решения

## LESSON m05-1 | if — «если» | 7
:: goals
- Как выполнить код только при условии
- Знаки сравнения
- Что такое блок

:: text Если… то…
Игра постоянно задаёт вопросы:
- Здоровье кончилось? → показать «Game Over».
- Собрал 10 монет? → открыть дверь.

Для этого есть `if` («если»):

```gd
if health <= 0:
	print("Game Over")
```

Читается: «если здоровье меньше или равно нулю, напечатай Game Over».

Строки **с отступом** под `if` — это **блок**. Они выполнятся, только если условие верно. Двоеточие `:` в конце строки обязательно.

:: text Знаки сравнения
- `==` — равно (два знака `=`!)
- `!=` — не равно
- `<` — меньше, `>` — больше
- `<=` — меньше или равно, `>=` — больше или равно

Результат сравнения — `true` (правда) или `false` (ложь). Это тип `bool`.

!> `=` — «положи в коробку». `==` — «равно ли?». Перепутать их — очень частая ошибка.

:: code
```gd
extends Node

func _ready():
	var coins = 12
	print(coins > 10)
	print(coins == 5)
	if coins >= 10:
		print("Хватает на ключ!")
	print("Конец проверки")
```
```out
true
false
Хватает на ключ!
Конец проверки
```
Последняя строка без отступа — она **вне** блока `if` и печатается всегда. Поменяй `coins` на 3 и запусти снова.

:: quiz
Что напечатает код?
```gd
var hp = 0
if hp > 0:
	print("Жив")
print("Ход окончен")
```
[ ] `Жив` и `Ход окончен` => `hp > 0` — ложь, ведь 0 не больше 0.
[x] Только `Ход окончен` => Верно. Блок `if` пропущен, а последняя строка вне блока.
[ ] Ничего => Последняя строка без отступа, она выполнится всегда.

:: fill
Допиши условие: напечатать «Победа!», если очков ровно 100.
```gd
extends Node

func _ready():
	var score = 100
	___ score ___ 100:
		print("Победа!")
```
= if
= ==
explain: Для сравнения нужен двойной знак `==`.

:: recap
- `if условие:` — блок с отступом выполнится, только если условие верно.
- Сравнения: `==`, `!=`, `<`, `>`, `<=`, `>=`.
- `=` кладёт значение, `==` сравнивает.

## LESSON m05-2 | else и elif | 7
:: goals
- Что делать, если условие не выполнилось
- Как проверить несколько вариантов по очереди

:: text else — «иначе»
`else` («иначе») — блок, который выполнится, если условие **не** выполнилось.

```gd
if health > 0:
	print("Играем дальше")
else:
	print("Game Over")
```

Выполнится ровно **один** из двух блоков. Никогда оба.

:: text elif — «иначе если»
Если вариантов больше двух, есть `elif` (else + if):

```gd
if score >= 90:
	print("Золото")
elif score >= 50:
	print("Серебро")
else:
	print("Попробуй ещё")
```

Godot проверяет условия **сверху вниз**. Первое верное — его блок выполнится. Остальные пропускаются.

:: code
Поменяй `score` на 95, на 50 и на 10. Каждый раз запускай.
```gd
extends Node

func _ready():
	var score = 70
	if score >= 90:
		print("Золото")
	elif score >= 50:
		print("Серебро")
	else:
		print("Попробуй ещё")
```
```out
Серебро
```

:: quiz
`score = 95`. Что напечатает код из примера?
[x] `Золото` => Верно. Первое условие верно, остальные даже не проверяются.
[ ] `Золото` и `Серебро` => 95 ≥ 50 тоже верно, но после первого совпадения проверка останавливается.
[ ] `Серебро` => Первым проверяется `score >= 90` — оно верно.

:: order
Собери проверку температуры: выше 30 — «Жарко», иначе — «Нормально».
```gd
extends Node
func _ready():
	var t = 35
	if t > 30:
		print("Жарко")
	else:
		print("Нормально")
```

:: task
Переменная `hp` — здоровье от 0 до 100. Напечатай:
- `Здоров`, если hp больше 70;
- `Ранен`, если hp от 1 до 70;
- `Повержен`, если hp равно 0 или меньше.

Сейчас `hp = 40`, должно напечататься `Ранен`. Проверь и другие числа.
```gd
extends Node

func _ready():
	var hp = 40
```
```solution
extends Node

func _ready():
	var hp = 40
	if hp > 70:
		print("Здоров")
	elif hp > 0:
		print("Ранен")
	else:
		print("Повержен")
```
```expect
Ранен
```
hint: Три варианта — значит `if`, `elif` и `else`.
hint: Сначала проверь самое строгое: `hp > 70`. Потом `hp > 0`.

:: recap
- `else:` — блок «иначе», если условие ложно.
- `elif условие:` — ещё одна проверка.
- Проверки идут сверху вниз; выполняется только первый подошедший блок.

## LESSON m05-3 | and, or, not | 7
:: goals
- Как соединить два условия
- Как перевернуть условие

:: text Три слова-связки
- `and` («и») — верно, если **оба** условия верны.
- `or` («или») — верно, если **хотя бы одно** верно.
- `not` («не») — переворачивает: правда становится ложью и наоборот.

```gd
if has_key and door_near:
	print("Открыть дверь")

if hp <= 0 or time_left <= 0:
	print("Game Over")

if not is_paused:
	print("Игра идёт")
```

:: code
```gd
extends Node

func _ready():
	var has_key = true
	var coins = 3
	print(has_key and coins >= 5)
	print(has_key or coins >= 5)
	print(not has_key)
	if has_key and coins >= 3:
		print("Можно войти в магазин")
```
```out
false
true
false
Можно войти в магазин
```

:: quiz
`is_night = true`, `has_torch = false`. Что даст `is_night and not has_torch`?
[x] `true` => Верно. Ночь — правда, «нет факела» — тоже правда. Оба верны.
[ ] `false` => Разберём: `not has_torch` = `not false` = `true`. И `is_night` = `true`.
[ ] Ошибку => Ошибки нет, так писать можно.

:: task
Игрок может прыгнуть, если он **на земле** и **не оглушён**. Напечатай `Прыжок!`, если можно, и `Нельзя`, если нельзя.
```gd
extends Node

func _ready():
	var on_floor = true
	var stunned = false
```
```solution
extends Node

func _ready():
	var on_floor = true
	var stunned = false
	if on_floor and not stunned:
		print("Прыжок!")
	else:
		print("Нельзя")
```
```expect
Прыжок!
```
hint: Нужны оба условия: `and`.
hint: «Не оглушён» — `not stunned`.

:: recap
- `and` — оба верны, `or` — хоть одно верно, `not` — наоборот.
- Переменную типа bool можно сразу ставить в условие: `if is_alive:`.

## LESSON m05-4 | match — выбор из вариантов | 7
:: goals
- Как выбрать действие по значению
- Что такое `_` в match

:: text match — как переключатель
Когда одну переменную сравнивают со многими значениями, цепочка `elif` получается длинной. Для этого есть `match` («сопоставь»):

```gd
match weapon:
	"меч":
		print("Удар мечом")
	"лук":
		print("Выстрел")
	_:
		print("Удар кулаком")
```

Godot берёт значение `weapon` и ищет совпадающую ветку. `_` означает «всё остальное» — как `else`.

:: code
```gd
extends Node

func _ready():
	var day = 6
	match day:
		1, 2, 3, 4, 5:
			print("Будний день")
		6, 7:
			print("Выходной!")
		_:
			print("Такого дня нет")
```
```out
Выходной!
```
Несколько значений через запятую — одна ветка для всех.

:: text Когда что выбирать
- `match` — когда сравниваешь **одно значение** с конкретными вариантами: состояние персонажа, тип предмета, номер уровня.
- `if/elif` — когда условия сложнее: `>`, `<`, `and`, `or`.

> Позже мы будем использовать `match` для состояний персонажа: стоит, бежит, прыгает.

:: quiz
Что делает ветка `_:` в `match`?
[ ] Проверяет пустую строку => Нет. `_` значит «любое другое значение».
[x] Срабатывает, если не подошла ни одна ветка выше => Верно. Это как `else`.
[ ] Ничего, это опечатка => Это специальный знак в `match`.

:: task
По номеру `level` напечатай название мира:
- 1 → `Лес`
- 2 → `Пещера`
- 3 → `Замок`
- любое другое → `Неизвестно`

Сейчас `level = 2`.
```gd
extends Node

func _ready():
	var level = 2
```
```solution
extends Node

func _ready():
	var level = 2
	match level:
		1:
			print("Лес")
		2:
			print("Пещера")
		3:
			print("Замок")
		_:
			print("Неизвестно")
```
```expect
Пещера
```
hint: Начни с `match level:`, внутри — ветки `1:`, `2:`, `3:`, `_:`.
hint: Под каждой веткой — `print` с ещё одним отступом.

:: recap
- `match значение:` выбирает ветку с совпавшим значением.
- Несколько значений в ветке — через запятую: `6, 7:`.
- `_:` — «всё остальное».
