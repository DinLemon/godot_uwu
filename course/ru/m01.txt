# MODULE m01 | Установка и первый проект | Скачиваем Godot и открываем редактор

## LESSON m01-1 | Скачать Godot | 5
:: goals
- Где скачать Godot
- Какую версию выбрать
- Как запустить

:: text Какая версия нужна
visual: concept-m01
Курс написан для **Godot 4**. Бери последнюю стабильную (stable) версию из ветки 4.

!> Не бери Godot 3. Многое в нём устроено по-другому, и примеры из курса там не заработают.

Есть две сборки:
- **Godot Engine** — обычная. Её и бери.
- **Godot Engine — .NET** — для языка C#. В этом курсе он не нужен.

:: steps Скачиваем
visual: guide-m01-1-0
- Открой сайт [godotengine.org/download](https://godotengine.org/download).
- Сайт сам определит твою систему (Windows, macOS, Linux). Нажми большую кнопку **Godot Engine** (не .NET).
- Скачается архив .zip. Распакуй его в удобную папку, например `Документы/Godot`.
- Внутри будет файл программы (на Windows — `Godot_v4…_win64.exe`). Запусти его двойным кликом.
- Если Windows спросит «Запустить неизвестную программу?», нажми «Подробнее» → «Выполнить в любом случае». Godot безопасен — это официальный сайт.

> Godot не нужно устанавливать. Это один файл. Его можно носить даже на флешке.

:: text Ещё способ: Steam
Godot есть в Steam — бесплатно. Там он обновляется сам. Если пользуешься Steam, это удобно.

:: quiz
Какую сборку Godot скачать для этого курса?
[x] Godot Engine 4 (обычную) => Верно. Мы пишем на GDScript, обычной сборки хватает.
[ ] Godot Engine — .NET => Она для языка C#. Нам не нужна.
[ ] Godot 3 => Это старая ветка. Код курса там не заработает.

:: recap
- Нужен **Godot 4**, обычная сборка (не .NET).
- Godot — один файл, устанавливать не надо.

## LESSON m01-2 | Менеджер проектов | 6
:: goals
- Что такое проект
- Как создать новый проект
- Какой выбрать рендерер

:: text Проект — это папка
**Проект** — это папка с твоей игрой. В ней лежат всё: картинки, звуки, сцены, скрипты.

В корне папки есть файл `project.godot`. По нему Godot понимает: «это мой проект».

Когда запускаешь Godot, первым открывается **Менеджер проектов** (Project Manager). Это список твоих игр.

:: steps Создаём проект
visual: guide-m01-2-0
- Запусти Godot. Откроется Менеджер проектов.
- Нажми **Create** (Создать) или **+ Create** вверху слева.
- В поле **Project Name** напиши `Pervaya Igra` или `my_first_game`.
- Нажми **Browse** и выбери, где будет папка проекта. Галочку **Create Folder** оставь включённой.
- В блоке **Renderer** выбери **Compatibility** (совместимость) — подробнее на следующем шаге.
- Нажми **Create & Edit** (в новых версиях просто **Create**). Откроется редактор.

!> Называй проекты и файлы латиницей, без пробелов: `my_game`, а не `Моя игра`. Так меньше странных ошибок при экспорте.

:: text Какой рендерер выбрать
Рендерер — это способ, которым Godot рисует картинку. Их три:

- **Forward+** — самый красивый, для 3D на мощных компьютерах.
- **Mobile** — для телефонов.
- **Compatibility** — работает почти везде, даже на старых ноутбуках и **в браузере**.

Для этого курса бери **Compatibility**. Мы делаем 2D, а в конце выложим игру в интернет — для браузера нужен именно он.

> Рендерер можно поменять потом: Project → Project Settings → Rendering.

:: quiz
Зачем в этом курсе рендерер **Compatibility**?
[ ] Он самый красивый => Самый красивый — Forward+. Но он не работает в браузере.
[x] Он работает почти везде, в том числе в браузере => Верно. В конце курса мы выложим игру в интернет.
[ ] Без него нельзя писать скрипты => Скрипты работают с любым рендерером.

:: recap
- Проект — это папка с файлом `project.godot`.
- Новый проект создаётся в Менеджере проектов: **Create**.
- Рендерер для курса — **Compatibility**.
- Имена файлов — латиницей, без пробелов.

## LESSON m01-3 | Окно редактора | 7
:: goals
- Четыре главные панели редактора
- Как переключаться между 2D, 3D и скриптом
- Как поменять язык интерфейса

:: text Язык интерфейса
Godot сам выбирает язык по системе. Может открыться на русском.

В курсе названия кнопок даны **по-английски**, а в скобках — перевод. Почему: почти все уроки, видео и ответы в интернете — с английским интерфейсом. Так проще искать помощь.

Поменять язык: **Editor → Editor Settings → Interface → Editor → Editor Language**. Нужен перезапуск редактора.

:: text Четыре главные панели
Редактор похож на кабину самолёта. Но важных мест всего четыре:

1. **Scene** (Сцена) — слева вверху. Дерево узлов текущей сцены.
2. **FileSystem** (Файловая система) — слева внизу. Все файлы проекта.
3. **Viewport** (Окно просмотра) — в центре. Здесь видно игру и узлы.
4. **Inspector** (Инспектор) — справа. Свойства выбранного узла: позиция, цвет, размер.

```tree
┌──────────┬───────────────────────┬────────────┐
│ Scene    │                       │ Inspector  │
│ (дерево) │       Viewport        │ (свойства) │
├──────────┤   (центр, игра тут)   │            │
│FileSystem│                       │            │
│ (файлы)  │                       │            │
└──────────┴───────────────────────┴────────────┘
```

:: text Вкладки сверху
Над центральным окном есть вкладки: **2D**, **3D**, **Script**, **AssetLib**.

- **2D** — редактор двумерной сцены. Будем жить здесь.
- **3D** — для трёхмерных сцен.
- **Script** — редактор кода.
- **AssetLib** — библиотека бесплатных дополнений.

Горячие клавиши: `Ctrl+F1` — 2D, `Ctrl+F2` — 3D, `Ctrl+F3` — Script.

:: quiz
Ты выбрал узел и хочешь поменять его цвет. Где искать?
[ ] В панели FileSystem => Там лежат файлы. Свойства узла — в другом месте.
[ ] В панели Scene => Там дерево узлов. Можно выбрать узел, но не поменять свойства.
[x] В панели Inspector => Верно. Инспектор показывает все свойства выбранного узла.

:: steps Осмотрись
lab: editor-tour
visual: guide-m01-3-0
- Найди панель **Scene** слева вверху. Сейчас там кнопки «2D Scene», «3D Scene», «User Interface».
- Найди **FileSystem** слева внизу. Там уже есть файл `icon.svg` — логотип Godot.
- Найди **Inspector** справа. Пока он пустой: ничего не выбрано.
- Пощёлкай вкладки **2D**, **3D**, **Script** над центром. Вернись на **2D**.

:: text Кнопки запуска
Справа вверху есть кнопки запуска:

- ▶ **Run Project** (`F5`) — запустить игру с главной сцены.
- **Run Current Scene** (`F6`) — запустить только открытую сцену.
- ■ **Stop** (`F8`) — остановить.

Запускать пока нечего. Сделаем это в следующем модуле.

:: recap
- Четыре панели: **Scene**, **FileSystem**, **Viewport**, **Inspector**.
- Вкладки **2D / 3D / Script** переключают центральное окно.
- `F5` — запустить игру, `F6` — текущую сцену, `F8` — стоп.
