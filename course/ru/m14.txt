# MODULE m14 | Создание и удаление | Сцены-шаблоны, пули, враги и группы

## LESSON m14-1 | Сцена как шаблон | 7
:: goals
- Что значит «инстанцировать» сцену
- Как вставить сцену в другую мышкой

:: text Экземпляр
visual: concept-m14
Ты уже знаешь: сцену делают один раз, а используют много раз. Каждая копия называется **экземпляром** (instance). Создать копию — **инстанцировать**.

У всех экземпляров общий «чертёж». Поменяешь что-то в `coin.tscn` — изменятся все монетки на всех уровнях.

А у каждого экземпляра свои значения: позиция, и всё, что помечено `@export`.

:: steps Монетка-шаблон
visual: guide-m14-1-0
- **Scene → New Scene**, корень **Area2D**, назови `Coin`.
- Добавь **Sprite2D** с `icon.svg`. В Инспекторе поставь **Scale** = `0.3, 0.3` — пусть будет маленькой.
- Добавь **CollisionShape2D** с **New CircleShape2D** под размер картинки.
- Сохрани как `coin.tscn`.
- Открой `level.tscn`. Перетащи `coin.tscn` из FileSystem в окно 2D. Ещё раз. И ещё. Получилось три монетки.
- У экземпляров в дереве есть иконка «хлопушки» 🎬 — это значит «тут вставлена сцена». Клик по ней открывает её чертёж.

:: quiz
Ты перекрасил монетку в `coin.tscn` в жёлтый. Что будет с монетками на уровне?
[x] Все станут жёлтыми => Верно. Экземпляры следуют за своим чертежом.
[ ] Ничего, они уже на уровне => Экземпляры связаны с файлом сцены.
[ ] Только первая станет жёлтой => Нет, все одинаково.

:: recap
- **Экземпляр** — копия сцены внутри другой сцены.
- Изменения в чертеже (`.tscn`) меняют все экземпляры.
- Вставить мышкой: перетащить `.tscn` в окно 2D (или `Ctrl+Shift+A`).

## LESSON m14-2 | Создание из кода: preload и instantiate | 8
:: goals
- Как создать экземпляр сцены кодом
- Что такое PackedScene

:: text Три шага
Пули, враги, взрывы появляются во время игры. Их создают кодом:

```gd
const BULLET = preload("res://bullet.tscn")   # 1. загрузить чертёж

func shoot():
	var b = BULLET.instantiate()                # 2. сделать копию
	b.position = position                       #    настроить
	get_parent().add_child(b)                   # 3. добавить в дерево
```

1. `preload` загружает сцену из файла. Получается **PackedScene** — упакованный чертёж.
2. `instantiate()` делает из чертежа живое дерево узлов.
3. `add_child()` вставляет его в игру. Пока не добавили — его нет на экране.

!> Пулю добавляют в **уровень** (`get_parent()`), а не в игрока. Иначе пуля станет ребёнком игрока и будет двигаться вместе с ним.

:: code
Это код для Godot: в тренажёре нет файлов `.tscn`.
```gd
extends Node2D

@export var enemy_scene: PackedScene

func _ready():
	for i in 3:
		var e = enemy_scene.instantiate()
		e.position = Vector2(100 + i * 80, 200)
		add_child(e)
```
norun: yes
Вариант с `@export var enemy_scene: PackedScene`: сцену врага перетаскивают в поле Инспектора. Так скрипт не зависит от пути к файлу.

:: text В тренажёре — через new()
В тренажёре узлы создают через `Тип.new()`. Это как `instantiate()`, только для одного узла без сцены.

```gd
var n = Node2D.new()   # один пустой узел
add_child(n)
```

:: code
```gd
extends Node2D

func _ready():
	for i in 3:
		var coin = Node2D.new()
		coin.name = "Coin" + str(i + 1)
		coin.position = Vector2(i * 50, 0)
		add_child(coin)
	add_child(Node2D.new())
	print_tree_pretty()
	print(get_child_count())
	print($Coin3.position)
```
```out
 ┖╴Main
    ┠╴Coin1
    ┠╴Coin2
    ┠╴Coin3
    ┖╴@Node2D@2
4
(100.0, 0.0)
```
Имена соседей в дереве должны быть разными. Последнему узлу мы имя не дали — Godot придумал служебное: `@Node2D@` и номер. В Godot номер будет другим. Если нужно имя попроще, пиши `add_child(узел, true)` — получится `Node2D`, `Node2D2` и так далее.

:: fill
Допиши создание врага из чертежа.
```gd
extends Node2D

const ENEMY = ___("res://enemy.tscn")

func spawn():
	var e = ENEMY.___()
	___(e)
```
= preload
= instantiate
= add_child
explain: Загрузить — `preload`, сделать копию — `instantiate`, добавить в дерево — `add_child`.

:: recap
- `preload("res://x.tscn")` — загрузить чертёж (PackedScene).
- `.instantiate()` — сделать экземпляр.
- `add_child(узел)` — добавить в дерево. Без этого узла нет в игре.

## LESSON m14-3 | Удаление: queue_free | 7
:: goals
- Как убрать узел из игры
- Почему «queue»

:: text queue_free — удалить
Монетку подобрали, враг побеждён, пуля улетела — их надо удалить:

```gd
queue_free()
```

**queue** — «очередь». Узел удаляется не сразу, а **в конце текущего кадра**. Так безопаснее: другой код в этом кадре ещё может к нему обратиться без ошибки.

Удаляется узел **вместе со всеми детьми**.

:: code
Пуля летит и удаляет себя, когда улетит дальше 100 пикселей. Здесь пуля — **внутренний класс**: маленький скрипт внутри скрипта. Подробно про классы — в модуле 19.
```gd
extends Node2D
# тренажёр: кадров=4 дельта=0.5

class Bullet extends Node2D:
	var speed = 100

	func _process(delta):
		position.x += speed * delta
		print("пуля: ", position.x)
		if position.x >= 100:
			print("пуля улетела")
			queue_free()

func _ready():
	add_child(Bullet.new())

func _process(delta):
	print("детей: ", get_child_count())
```
```out
детей: 1
пуля: 50.0
детей: 1
пуля: 100.0
пуля улетела
детей: 0
детей: 0
```
На кадре, где пуля вызвала `queue_free()`, она ещё есть. Её удалили в конце кадра.

:: text После удаления
К удалённому узлу обращаться нельзя — будет ошибка. Если не уверен, жив ли узел, проверь:

```gd
if is_instance_valid(enemy):
	enemy.take_damage(1)
```

:: quiz
Что произойдёт с детьми узла после `queue_free()`?
[x] Удалятся вместе с ним => Верно. Удаляется всё поддерево.
[ ] Перейдут к его родителю => Нет, они удаляются.
[ ] Останутся висеть без родителя => Так не бывает: дети удаляются.

:: recap
- `queue_free()` — удалить узел в конце кадра вместе с детьми.
- После удаления узлом пользоваться нельзя. Проверка — `is_instance_valid(x)`.

## LESSON m14-4 | Группы | 7
:: goals
- Что такое группа
- Как найти все узлы группы
- Как вызвать функцию у всех сразу

:: text Ярлык для узлов
**Группа** — ярлык, который можно повесить на узлы. Например, все враги — в группе `enemies`. Узел может быть в нескольких группах.

Добавить в группу:
- мышкой: вкладка **Node → Groups**, вписать имя, **Add**;
- кодом: `add_to_group("enemies")`.

Проверить: `is_in_group("enemies")`.

:: text Что даёт группа
`get_tree()` — доступ ко всему дереву игры. Через него:

- `get_tree().get_nodes_in_group("enemies")` — массив всех врагов;
- `get_tree().call_group("enemies", "freeze")` — вызвать `freeze()` у каждого врага.

Это удобно для «бомбы на весь экран» или паузы всех врагов.

:: code
```gd
extends Node

class Enemy extends Node:
	var hp = 3
	func _ready():
		add_to_group("enemies")
	func hit(dmg):
		hp -= dmg
		print(name, ": осталось ", hp)

func _ready():
	for i in 3:
		var e = Enemy.new()
		e.name = "Enemy" + str(i + 1)
		add_child(e)
	add_child(Node.new())
	var enemies = get_tree().get_nodes_in_group("enemies")
	print("Врагов: ", enemies.size())
	get_tree().call_group("enemies", "hit", 2)
```
```out
Врагов: 3
Enemy1: осталось 1
Enemy2: осталось 1
Enemy3: осталось 1
```
Обычный `Node` не в группе — его урон не задел.

:: quiz
Монетка проверяет, кто в неё вошёл. Как надёжнее узнать, что это игрок?
[x] `if body.is_in_group("player"):` => Верно. Группа не зависит от имени узла.
[ ] `if body.name == "Player":` => Работает, пока узел так называется. Переименуешь — сломается.
[ ] Никак => Можно: через группы или имя.

:: recap
- **Группа** — ярлык для узлов: `add_to_group("x")`, `is_in_group("x")`.
- `get_tree().get_nodes_in_group("x")` — все узлы группы.
- `get_tree().call_group("x", "функция")` — вызвать у всех.

## LESSON m14-p | Практика: спавнер | 8 | practice
:: goals
- Создание узлов, таймер и удаление вместе

:: task
Каждую секунду появляется новый враг (узел `Node2D`). Когда врагов становится 3, спавнер останавливается и печатает `Хватит`.

Таймер уже создан. Допиши функцию `_on_spawn`:
- создать `Node2D`, добавить его в дерево и напечатать `Враг №N`;
- если детей-врагов стало 3 — остановить таймер (`timer.stop()`) и напечатать `Хватит`.

Таймер — тоже ребёнок, поэтому врагов считаем отдельной переменной `count`.
```text
Враг №1
Враг №2
Враг №3
Хватит
```
```gd
extends Node
# тренажёр: кадров=10 дельта=0.5

var timer
var count = 0

func _ready():
	timer = Timer.new()
	add_child(timer)
	timer.timeout.connect(_on_spawn)
	timer.start()

func _on_spawn():
	pass
```
```solution
extends Node
# тренажёр: кадров=10 дельта=0.5

var timer
var count = 0

func _ready():
	timer = Timer.new()
	add_child(timer)
	timer.timeout.connect(_on_spawn)
	timer.start()

func _on_spawn():
	var enemy = Node2D.new()
	add_child(enemy)
	count += 1
	print("Враг №", count)
	if count >= 3:
		timer.stop()
		print("Хватит")
```
```expect
Враг №1
Враг №2
Враг №3
Хватит
```
hint: Создать: `var enemy = Node2D.new()`, потом `add_child(enemy)`.
hint: Счётчик `count += 1` и проверка `if count >= 3:`.

:: recap
- Спавнер = таймер + создание узла в функции-получателе сигнала `timeout`.
- Счётчик помогает вовремя остановиться.
