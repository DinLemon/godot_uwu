# Godot с нуля

Интерактивный курс по Godot 4 и GDScript для тех, кто никогда не делал игр и не программировал. Написан простым буквальным языком для людей, которым трудно долго держать внимание (СДВГ), и с учётом особенностей аутичного восприятия: предсказуемая структура, план в начале каждого урока, подписанные аналогии, одна мысль на экран, необязательные «углубления» для тех, кому интересны детали.

- 24 модуля, 101 урок, около 13 часов — от «что такое движок» до готовой игры на itch.io.
- **Тренажёр GDScript прямо в браузере**: свой интерпретатор подмножества GDScript 2.0. Переменные, типы, функции, классы, сигналы, массивы, словари, Vector2/3, дерево узлов, кадры `_process`, ввод, таймеры, `CharacterBody2D` с полом. Без сервера и интернета.
- Ошибки показываются как в Godot, плюс объяснение по-русски.
- Шаги «Сделай в Godot» — чек-листы для настоящего редактора.
- Задачи с проверкой вывода, подсказками в несколько уровней и решением; «заполни пропуск», «собери код», вопросы.
- Повторение с упором на вопросы, где была ошибка; шпаргалка; словарь (100 терминов).
- Код в примерах — с табами, как в Godot: его можно копировать в редактор кнопкой «Скопировать».
- Прогресс сохраняется в браузере сам, его можно выгрузить в файл и загрузить обратно.
- Светлая и тёмная тема, размер шрифта, отключение анимаций, фокус-режим.

## Как открыть

Сайт статический, сборка не нужна. Открой `index.html` в браузере или опубликуй репозиторий через GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch → `main`, папка `/ (root)`**.

## Как устроено

```
index.html              страница курса
css/style.css           стили (без внешних шрифтов)

js/gdscript.js          тренажёр: лексер, парсер и интерпретатор GDScript

content/course-data.js  сгенерированные данные (не редактировать вручную)
tools/build.py          собирает course/*/*.txt → content/course-data.js
tools/tabify.py         превращает отступы в 4 пробела внутри кода в табы
tools/check_gd.js       прогоняет все примеры и решения через тренажёр
```

### Настройки тренажёра

Строка-комментарий в коде примера управляет симуляцией кадров. В Godot она ничего не делает.

```
# тренажёр: кадров=4 дельта=0.25 нажато=ui_right,jump@2-3 пол=0 имя=Player
```

- `кадров` — сколько раз вызвать `_physics_process` и `_process` (по умолчанию 3);
- `дельта` — значение `delta` (по умолчанию 0.25);
- `нажато` — какие действия зажаты: все кадры, `@2` — только 2-й, `@2-4` — со 2-го по 4-й;
- `пол` — y, ниже которого `CharacterBody2D` стоит на полу (`is_on_floor()`);
- `имя` — имя корневого узла (по умолчанию `Main`).
