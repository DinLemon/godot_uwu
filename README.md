# Godot UwU

[Открыть курс →](https://dinlemon.github.io/godot_uwu/)

Интерактивный курс по Godot 4 и GDScript для тех, кто никогда не делал игр и не программировал. Написан простым буквальным языком для людей, которым трудно долго держать внимание (СДВГ), и с учётом особенностей аутичного восприятия: предсказуемая структура, план в начале каждого урока, подписанные аналогии, одна мысль на экран, необязательные «углубления» для тех, кому интересны детали.

- 24 модуля, 113 уроков, около 15 часов — от «что такое движок» до готовой игры на itch.io.
- **12 мастерских** дополняют основные уроки: открытка-сцена, журнал запуска, магазин, локальные координаты, управление, прыжок, сигналы, анимация, адаптивное меню, таймер, проверка сохранений и приёмка игры. В каждой есть опыт, ожидаемый результат, действия в Godot и разбор ошибки.
- **84 перехода к практике в 71 уроке**: блок «Закрепить в редакторе» открывает задание и сохраняет в ссылке точный шаг возвращения. Выполненные задания отмечены; проходить их можно в своём темпе. Прежние идентификаторы уроков и порядок старых карточек сохранены.
- **Тренажёр GDScript прямо в браузере**: свой интерпретатор подмножества GDScript 2.0. Переменные, типы, функции, классы, сигналы, массивы, словари, Vector2/3, дерево узлов, кадры `_process`, ввод, таймеры, `CharacterBody2D` с полом. Без сервера и интернета.
- Ошибки показываются как в Godot, плюс объяснение по-русски.
- Шаги «Сделай в Godot» — чек-листы для настоящего редактора.
- **20 практических заданий в учебном редакторе**: дерево Scene, создание узлов, Inspector, предпросмотр, Input Map, сигналы, ключи анимации, кисти TileMapLayer, камера, таймер, отладка и небольшой игровой тест. [Открыть практику →](https://dinlemon.github.io/godot_uwu/#/practice)
- Интерфейс практики следует стандартной раскладке Godot 4: меню Scene / Project / Debug / Editor / Help, дерево Scene и FileSystem слева, Inspector / Signals справа, нижние Output / Debugger / Animation. Input Map открывается через Project Settings; запуск переключает на Game. Панели показывают учебную модель, не полный редактор Godot.
- Объекты можно выбирать и перетаскивать прямо в 2D-сцене, сдвигать стрелками, дублировать вместе с детьми и переносить к другому родителю. Есть отмена/повтор и показ форм столкновений. Нарисованный участок TileMapLayer можно запустить; клавиатура управляет движением и прыжком. Ключи анимации можно проиграть, не двигая курсор вручную.
- Проверка практики оценивает состояние сцены и результат запуска: допускает свои названия, дополнительные узлы и значения в заданных диапазонах. Состояние каждого задания сохраняется отдельно и входит в экспорт прогресса. Это учебная модель интерфейса, а не запущенный Godot; ограничения объясняются в заданиях.
- 77 наглядных схем, в том числе ориентиры для всех 53 карточек «Сделай в Godot». Выбери номер действия, чтобы увидеть нужную панель и прочитать инструкцию. В мастерских отдельно указано, что проверяет учебная модель и что нужно испытать в настоящем Godot.
- На главной лисичка с геймпадом приветствует по клику, пробует игру и радуется успеху. Реакции учитывают выключенные анимации и системное предпочтение уменьшенного движения.
- Задачи с проверкой вывода, подсказками в несколько уровней и решением; «заполни пропуск», «собери код», вопросы.
- Повторение с упором на вопросы, где была ошибка; шпаргалка; словарь (100 терминов).
- Код в примерах — с табами, как в Godot: его можно копировать в редактор кнопкой «Скопировать».
- Прогресс сохраняется в браузере сам, его можно выгрузить в файл и загрузить обратно.
- Светлая и тёмная тема, размер шрифта, отключение анимаций, фокус-режим.

## Как открыть

Сайт статический, сборка не нужна. Открой `index.html` в браузере или опубликуй репозиторий через GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch → `main`, папка `/ (root)`**.

~~~
# MODULE m01 | Название модуля | Подзаголовок
## LESSON m01-1 | Название урока | 6          ← минуты
## LESSON m01-p | Практика | 10 | practice   ← урок-практика

:: goals                       ← «В этом уроке»
- пункт

:: text Заголовок              ← текст: **жирный**, `код`, списки, > совет, !> предупреждение,
                                  ```gd код```, ```tree дерево узлов```
visual: concept-m04            ← необязательная схема из course/visuals.json
:: code                        ← пример, который запускается в тренажёре
Описание.
```gd
extends Node

    print("hi")
```

```
Текст после кода.
fails: yes                     ← пример специально падает с ошибкой
norun: yes                     ← код только для Godot (сцена, физика, файлы)

:: quiz
Вопрос?
[x] верный => почему
[ ] неверный => почему нет

:: fill                        ← пропуски ___ в коде, ответы по строке на пропуск
= ответ | вариант

:: order                       ← собрать строки в правильном порядке

:: task                        ← задача: ```gd заготовка, ```solution, ```expect, hint: …

:: steps Заголовок             ← чек-лист «Сделай в Godot»: строки "- …", после списка можно код

### Настройки тренажёра

Строка-комментарий в коде примера управляет симуляцией кадров. В Godot она ничего не делает.

```
# тренажёр: кадров=4 дельта=0.25 нажато=ui_right,jump@2-3 пол=0 имя=Player
```

- `кадров` — сколько раз вызвать `_physics_process` и `_process` (по умолчанию 3);
- `дельта` — значение `delta` (по умолчанию 0.25);
- `нажато` — какие действия зажаты: все кадры, `@2` — только 2-й, `@2-4` — со 2-го по 4-й;
- `пол` — y, ниже которого `CharacterBody2D` стоит на полу (`is_on_floor()`);
- `имя` — имя корневого узла (по умолчанию `Main`).

## После правки уроков

Схемы описаны в `course/visuals.json`. Для карточки `steps` число элементов `areas` должно совпадать с числом пунктов. Поле `frames` позволяет показать другое окно для конкретного действия. Сборщик проверяет, что ссылка на схему существует и все отмеченные области есть в выбранном окне.

Схемы упрощают интерфейс Godot 4 и подписаны как схемы. Положение панелей можно менять в самом Godot. Внутри соответствующих схем есть ссылки на документацию редактора, сигналов, Input Map и TileMapLayer.

Ссылки между уроками и редактором хранятся в `course/practice-links.json`: ключ — идентификатор урока, значение — список идентификаторов из `course/practice.json`. Сборщик проверяет обе стороны связи. Новые мастерские добавляются в конец модулей; существующие карточки не переставляются, чтобы сохранить ключи прогресса.

```
python3 tools/tabify.py      # пробелы → табы в коде
python3 tools/build.py       # пересобрать данные
node tools/check_gd.js       # проверить все примеры и решения
node tools/check_learning_path.js # проверить ссылки и возврат в урок
```
